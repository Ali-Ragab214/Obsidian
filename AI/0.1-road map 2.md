## 🗺️ الرودماب الكامل والمنظم (3 شهور، مرتكز على Java/Spring + هدفك)

### الاسبوع 1: الأساس + أول Feature حقيقي**

**أسبوع 1 — فهم LLMs + Prompt Engineering**

- Token, Context Window, Temperature, System/User/Assistant messages
- Zero-shot, Few-shot, Chain of Thought, Structured Output (JSON)
- **Practice:** جرب الـ prompts دي في Claude/OpenAI Console قبل الكود

**أسبوع 2 — APIs + Spring AI**

- Spring AI setup, ChatClient, Prompt Templates
- إزاي تتعامل مع Streaming responses
- Error handling, retries, API key security (env vars)
- **مشروع:** بسّط — chatbot endpoint واحد في Skill_Hub بيرد على أسئلة عامة

**أسبوع 3-4 — Function/Tool Calling + Structured Output**

- إزاي الـ LLM يقرر ينادي function بتاعتك (getMovieById, searchCourses..)
- ربط الـ Tool Calling بـ Spring AI `@Tool` أو function definitions
- JSON mode للـ responses المنظمة
- **مشروع:** AI endpoint في MovieApp بيرجع recommendations كـ JSON تستخدمه React مباشرة

---

### الاسبوع 2: RAG (الأهم في السوق فعليًا)**

**أسبوع 5 — Embeddings + Vector DB**

- يعني إيه إنك تحول text لـ vector
- جرب **pgvector** (extension على PostgreSQL، هيوفر عليك Docker container جديد لأنك أصلاً شغال Postgres)
- بديل: Qdrant لو عايز تتعلم vector DB متخصص

**أسبوع 6 — بناء RAG Pipeline**

```
Document → Chunking → Embedding → Store in Vector DB
                                        ↓
User Query → Embedding → Similarity Search → Retrieved Context → LLM → Answer
```

- Chunking strategies (size, overlap)
- Retrieval (top-k, similarity threshold)

**أسبوع 7-8 — مشروع RAG كامل**

- **مشروع مقترح:** "Skill_Hub AI Tutor" — يقرأ محتوى الكورسات، ويرد على أسئلة الطلاب بناءً على المحتوى الفعلي بس (مش معلومات عامة)
- ده فعليًا أقرب لمشروعك الحالي وهيفيدك أكتر من PDF Chat عشوائي

---

### **الشهر 3: Agents + Production**

**أسبوع 9 — Agents + MCP**

- Agent = LLM + Memory + Tools + Reasoning loop
- جرب MCP بسيط (زي اللي بتستخدمه دلوقتي معايا فعليًا!)
- **مشروع:** Agent بسيط في Skill_Hub يقدر "يبحث عن كورس → يلخصه → يقترح quiz"

**أسبوع 10 — Caching + Cost Optimization**

- Redis caching للـ AI responses (هتستخدم اللي بتتعلمه دلوقتي بالضبط)
- Prompt caching, token counting, اختيار الموديل المناسب (مش كل حاجة تحتاج أقوى موديل)

**أسبوع 11 — Security + Evaluation**

- Prompt Injection: امتى تحصل وإزاي تتجنبها
- إزاي تتأكد إن الـ AI بيرد صح (manual eval كافي في البداية)

**أسبوع 12 — Fine-tuning (نظري بس)**

- إيه الفرق بين RAG و Fine-tuning و Prompting (جدول مقارنة سريع)
- **الخلاصة العملية:** Fine-tuning غالبًا متبقاش تحتاجه إلا لو عندك use case متخصص جدًا وداتا كبيرة. RAG + Good Prompting بيغطوا تقريبًا كل حالات الـ web/mobile apps.
