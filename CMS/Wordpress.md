# 🎯 الأول: هل المشاريع تتحط في Pages ولا Posts؟

❌ غلط شائع: تحط كل مشروع في Page  
✅ الصح: تحط المشاريع كـ **Posts**

### ليه؟

- تقدر تعمل **Category اسمها Projects**
    
- تقدر تعرضهم كلهم في صفحة واحدة
    
- أسهل في الإدارة والتوسيع بعد كده

# 🧠 الفكرة الصح للـ Portfolio

- Projects

# 🔄 الفلو الكامل (Step by Step)

## 1️⃣ تعمل Pages

روح:  
👉 Pages → Add New

اعمل:

- Home
    
- About
    
- Contact
    
- Projects
    

---

## 2️⃣ تعمل Category

👉 Posts → Categories  
اعمل Category اسمها:  
👉 Projects

---

## 3️⃣ تضيف Projects كـ Posts

👉 Posts → Add New

كل مشروع:

- Title: اسم المشروع
    
- Content:
    
    - شرح المشروع
        
    - استخدمت اي (Spring / Laravel / etc)
        
    - صور من Media
        
- Category: Projects
    

---

## 4️⃣ تعرض المشاريع في صفحة Projects

### عندك طريقتين:

## 🔸 الطريقة السهلة:

تخلي صفحة Projects = Blog

👉 Settings → Reading  
اختار:

- Posts page = Projects
    

🔥 كده الصفحة هتعرض كل المشاريع تلقائي

---

## 🔸 الطريقة الاحترافية:

لو بتستخدم Elementor

- افتح صفحة Projects
    
- استخدم widget:  
    👉 Posts / Blog
    
- اعمل filter على Category = Projects
    

---

## 5️⃣ Media

👉 ارفع صور:

- screenshots للمشاريع
    
- logos
    

واستخدمهم جوه الـ posts

---

## 6️⃣ Menus

👉 Appearance → Menus

اعمل Menu:

- Home
    
- Projects
    
- About
    
- Contact
    

---

## 7️⃣ Users & Roles

- خليك Admin وخلاص

- Editor → يعدل المحتوى

# 1️⃣ ايه هو SureForms ؟

ده Plugin لعمل **Forms (فورم تواصل)** بسهولة.

يعني تعمل:

- Contact form
    
- Send message
    
- Send email
    

زي صفحة **Contact Me** بالظبط.

بداله المشهور كان Contact Form 7، لكن SureForms أسهل وأحدث.

### تقدر تعمل بيه:

- Name
    
- Email
    
- Message
    
- زرار Send
    
- يوصلك الإيميل لما حد يبعث رسالة
    

وده مطلوب في صفحة Contact في اللاب 💯

---

# 2️⃣ ايه هو Spectra ؟

ده Plugin تصميم قوي جدًا من شركة Astra.

يضيف Widgets جديدة لـ Gutenberg وElementor زي:

- Sections جاهزة
    
- Portfolio layouts
    
- Pricing tables
    
- Testimonials
    
- Counters
    
- Icons
    
- Animations
    

بمعنى بسيط:  
Elementor = أساس التصميم  
Spectra = أدوات تصميم احترافية زيادة

# ايه هو WooCommerce ؟

**WooCommerce** هو Plugin يحول WordPress إلى **متجر إلكتروني كامل**.

يعني بدل موقع عادي → يبقى Online Shop.

تقدر تبيع:

- منتجات
    
- كورسات
    
- خدمات
    
- ملفات PDF
    
- أي حاجة.
    

---

## بيضيف ايه للموقع؟

بعد تثبيته بيعمل صفحات تلقائي:

- Shop → صفحة المنتجات
    
- Cart → السلة
    
- Checkout → الدفع
    
- My Account → حساب المستخدم
    

ويضيف لوحة تحكم كاملة للمتجر.

---

## تستخدمه امتى؟

لو موقعك:

- Ecommerce
    
- Marketplace
    
- بيع خدمات أو منتجات
    

⚠️ لكن في لاب الـ Portfolio غالبًا مش مطلوب.

يعني تثبته بس لو عايز تتعلم أو تضيف متجر.

---

## ازاي تثبته؟

من Dashboard:

1. Plugins → Add New
    
2. ابحث:
    

```
WooCommerce
```

3. Install → Activate
    

بعد التفعيل هيبدأ Setup Wizard.

---

## Setup سريع (اعمله كده مؤقتًا)

هيسألك شوية أسئلة:

- Country → Egypt
    
- Currency → Egyptian Pound
    
- Product type → Physical products (أي اختيار مش مهم دلوقتي)
    

Next → Next → Finish.
