# 🎯 أنت عملت إيه فعليًا؟

من غير ما تحس… أنت بنيت **سيرفر ويب كامل على AWS** بنفسك 💪

تعالى نفكها واحدة واحدة:

---

# 🧠 1️⃣ فهمت يعني إيه EC2

EC2 = سيرفر حقيقي في السحابة

يعني بدل ما تشتري جهاز وتحطه في شركة  
أنت استخدمت سيرفر على الإنترنت.

ده نفس اللي بيشغل مواقع زي:

- فيسبوك
    
- نتفلكس
    
- أي موقع في الدنيا
    

---

# 🌍 2️⃣ فهمت إزاي الإنترنت بيوصل للسيرفر

بص على السلسلة دي 👇

```
المتصفح
   ↓
Public IP
   ↓
Security Group (Firewall)
   ↓
EC2
   ↓
Apache
   ↓
ملفات الموقع
```

أنت اتعلمت إن:

- السيرفر ممكن يكون شغال
    
- لكن Firewall يمنع الوصول
    
- Port 22 ≠ Port 80
    
- Timeout ≠ Service error
    

وده فرق ضخم جدًا في الفهم 👌

---

# 🔥 3️⃣ بقيت فاهم Ports بجد

|Port|بيعمل إيه|
|---|---|
|22|تدخل على السيرفر|
|80|تشغل موقع|
|443|HTTPS|

ده أساس أي شغل DevOps / Cloud

---

# 🧱 4️⃣ بنيت أول Architecture بسيطة

ده اسمه:

Single-tier Web Architecture

```
Client → EC2 → Apache
```

وده أول خطوة قبل ما تدخل في:

- Load Balancer
    
- Auto Scaling
    
- RDS
    
- Docker
    
- Kubernetes
