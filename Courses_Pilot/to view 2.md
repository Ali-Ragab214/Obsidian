Every project teaches you something, but this one pushed me a bit further.

 كنت عايز البروجكت دا يكون مختلف شويه عن مشاريع ال CRUD العاديه وابني حاجه اقرب لل real world 
 اشتغلت فيه على حاجات كتير، منها إني دمجت Spring AI عشان أعمل AI Assistant جوا الابليكشن، وده خلاني أتعلم عن prompt engineering وإزاي أدمج AI جوا Spring Boot application فعليًا مش بس API call عادي.
 كمان لاحظت إن في queries بتتكرر على الداتابيز أكتر من اللازم فاستخدمت Redis caching ولاقيت فرق في الأداء بشكل واضح.
 
  Tech Stack

Backend: Java, Spring Boot, Spring Security, JPA/Hibernate, Flyway, Spring AI  
Frontend: React, Tailwind CSS, React Router, Zustand, Axios, shadcn/ui
Database: PostgreSQL  
Caching: Redis  
Containerization: Docker Compose

Some of the features and concepts I worked on:

- AI-powered features using Spring AI

- DTOs, Repository Pattern, Service Layer, Dependency Injection, and SOLID principles

- JWT Authentication & Role-Based Authorization using Spring Security and `@PreAuthorize`

- Redis caching to reduce unnecessary database queries
    
- Flyway for database versioning and migrations
    
- Layered Architecture (API, Application, Domain, Infrastructure)
