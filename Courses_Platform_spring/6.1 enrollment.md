## أول حاجة — إيه الـ Enrollment؟

```
Student بيشوف Course
        │
        ▼
بيعمل Enroll (اشتراك)
        │
        ▼
بيقدر يشوف الـ Lessons
        │
        ▼
بيكمل الـ Lessons
        │
        ▼
الـ Progress بيتحدث
```

---

## الـ Business Logic — كل حالة وحالة

### 1. Enroll في Course

```
Student عايز يشترك في Course
        │
        ├── Course موجودة؟ → لأ → 404
        │
        ├── Course Published؟ → لأ → 400
        │   (مش هينفع يشترك في Draft)
        │
        ├── Student مشترك قبل كده؟ → آه → 409
        │   (Duplicate Enrollment)
        │
        └── كل حاجة تمام → احفظ الـ Enrollment ✅
```

### 2. Get My Enrollments

```
Student عايز يشوف الكورسات اللي مشترك فيها
        │
        └── جيب كل الـ Enrollments بتاعته مع Pagination
```

### 3. Check Enrollment

```
هل الـ Student مشترك في Course معينة؟
        │
        ├── آه → يقدر يشوف الـ Lessons ✅
        └── لأ → 403 Forbidden
```

### 4. Unenroll

```
Student عايز يلغي اشتراكه
        │
        ├── Enrollment موجودة؟ → لأ → 404
        └── امسح الـ Enrollment ✅
```

## الـ Enrollment Entity — فيها إيه؟

```
Enrollment
├── id          (من BaseEntity)
├── student     (FK → User)
├── course      (FK → Course)
├── progress    (0 → 100)
└── createdAt   (من BaseEntity = enrolled_at)
```

---

## الـ Plan خطوة بخطوة

### Phase 1 — Data Layer

```
1. EnrollmentRepository
   ├── findByStudentId (مع Pagination)
   ├── existsByStudentIdAndCourseId (للـ duplicate check)
   ├── findByStudentIdAndCourseId (للـ unenroll)
   └── countByCourseId (كام student في الـ course)
```

### Phase 2 — DTOs

```
2. EnrollmentRequest
   └── courseId فقط (الـ studentId هييجي من الـ JWT)

3. EnrollmentResponse
   ├── id
   ├── courseId
   ├── courseTitle
   ├── progress
   └── enrolledAt
```

### Phase 3 — Mapper

```
4. EnrollmentMapper
   └── toResponse(Enrollment) → EnrollmentResponse
```

### Phase 4 — Service

```
5. EnrollmentService (Interface)
   ├── enroll(courseId, studentEmail)
   ├── unenroll(enrollmentId, studentEmail)
   ├── getMyEnrollments(studentEmail, pageable)
   ├── isEnrolled(courseId, studentEmail)
   └── getEnrollmentCount(courseId)

6. EnrollmentServiceImpl
   └── بينفذ كل الـ logic فوق
```

### Phase 5 — Controller

```
7. EnrollmentController
   ├── POST   /api/enrollments          → enroll
   ├── DELETE /api/enrollments/{id}     → unenroll
   ├── GET    /api/enrollments/my       → getMyEnrollments
   └── GET    /api/enrollments/check/{courseId} → isEnrolled
```
