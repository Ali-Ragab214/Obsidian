# شرح Facade Design Pattern في Java

# 1) يعني إيه Facade Design Pattern؟

الـ **Facade Pattern** هو Design Pattern هدفه إنه:

> يقدملك واجهة بسيطة للتعامل مع System معقد.

بدل ما الـ Client or controller يتعامل مع Classes كتير وخطوات معقدة،  
بيتعامل مع Class واحدة اسمها:

```java
Facade
```

وهي اللي تتولى كل التفاصيل الداخلية.

---

# الفكرة ببساطة

بدل ما تعمل:

```java
paymentService.pay();
inventoryService.checkStock();
shippingService.ship();
notificationService.send();
```

هتعمل:

```java
orderFacade.placeOrder();
```

فالـ Facade بتخفي التعقيد.

# 4) مكونات Facade Pattern

## أول حاجة: Facade

وده الـ Class اللي العميل بيتعامل معاه.

مثال:

```java
OrderFacade
```

هو اللي بيلم كل العمليات المعقدة.

---

## ثاني حاجة: Subsystems

ودي الـ Classes الداخلية.

زي:

```java
PaymentService
InventoryService
ShippingService
NotificationService
```

كل واحدة مسئولة عن جزء معين.

# 5) مثال عملي كامل بـ Java

# مشروع E-Commerce

هنعمل سيستم طلب أوردر.

لما العميل يطلب منتج:

1. نتأكد إن المنتج موجود
    
2. نسحب الفلوس
    
3. نشحن المنتج
    
4. نبعت Email
    

---

# أولًا: الـ Subsystems

# Payment Service

```java
class PaymentService {

    public void makePayment(double amount) {
        System.out.println("تم دفع " + amount + " دولار");
    }
}
```

---

# Inventory Service

```java
class InventoryService {

    public void checkStock(String product) {
        System.out.println(product + " متوفر في المخزن");
    }
}
```

---

# Shipping Service

```java
class ShippingService {

    public void shipProduct(String product) {
        System.out.println("تم شحن المنتج: " + product);
    }
}
```

---

# Notification Service

```java
class NotificationService {

    public void sendEmail(String customer) {
        System.out.println("تم إرسال إيميل إلى " + customer);
    }
}
```

---

# ثانيًا: الـ Facade

```java
class OrderFacade {

    private PaymentService paymentService;
    private InventoryService inventoryService;
    private ShippingService shippingService;
    private NotificationService notificationService;

    public OrderFacade() {

        paymentService = new PaymentService();
        inventoryService = new InventoryService();
        shippingService = new ShippingService();
        notificationService = new NotificationService();
    }

    public void placeOrder(
            String product,
            double amount,
            String customer
    ) {

        System.out.println("بدء تنفيذ الأوردر...\n");

        inventoryService.checkStock(product);

        paymentService.makePayment(amount);

        shippingService.shipProduct(product);

        notificationService.sendEmail(customer);

        System.out.println("\nتم تنفيذ الأوردر بنجاح");
    }
}
```

---

# ثالثًا: الـ Client

```java
public class Main {

    public static void main(String[] args) {

        OrderFacade facade = new OrderFacade();

        facade.placeOrder(
                "Laptop",
                1500,
                "ali@example.com"
        );
    }
}
```

---

# الناتج

```text
بدء تنفيذ الأوردر...

Laptop متوفر في المخزن
تم دفع 1500 دولار
تم شحن المنتج: Laptop
تم إرسال إيميل إلى ali@example.com

تم تنفيذ الأوردر بنجاح
```

# 7) إمتى تستخدم Facade؟

استخدمه لما:

تخلي استخدام السيستم أسهل.

---

وتحب تغلفه بواجهة نظيفة.

---

## ✅ Layered Architecture

زي:

```text
Controller -> Service -> Repository
```

# 10) الفرق بين Facade و Patterns تانية

# Facade vs Adapter

## Facade

يبسط النظام.

---

## Adapter

يحوّل Interface لـ Interface تاني.

---

### مثال Adapter

```text
USB-C to HDMI
```

---

# Facade vs Proxy

## Facade

تبسيط.

---

## Proxy

تحكم في الوصول.

زي:

- Security
    
- Caching
    
- Lazy Loading
    

---

# Facade vs Mediator

## Facade

الـ Client يكلم الـ Facade.

---

## Mediator

الـ Objects تكلم بعض من خلال Mediator.

---

# جدول مقارنة سريع

|Pattern|الهدف|
|---|---|
|Facade|تبسيط النظام|
|Adapter|تحويل Interface|
|Proxy|التحكم في الوصول|
|Mediator|تنظيم التواصل|
