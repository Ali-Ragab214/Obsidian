### 5. مهم تفهم الفرق

- `RUN` → بيتنفذ وقت بناء الـ image
- `CMD` → بيتنفذ وقت تشغيل الـ container

### الخلاصة

السطر ده معناه:

> "لما الكونتينر يشتغل، شغّل تطبيق Java اللي اسمه app.jar"
---
## 1) ما هو Dockerfile؟

**الإجابة:**  
هو ملف فيه مجموعة تعليمات بتقول لـ Docker إزاي يبني Image لتطبيقك.


---
## 2) الفرق بين RUN و CMD؟

- `RUN` → بيتنفذ وقت بناء الـ image
- `CMD` → بيتنفذ وقت تشغيل الـ container

### مثال:

```
RUN mvn clean package
```

→ ده بيبني المشروع أثناء الـ build

```
CMD ["java","-jar","app.jar"]
```

→ ده بيشغل التطبيق وقت التشغيل

---
## 4) ما وظيفة COPY؟

ينقل ملفات من جهازك إلى داخل الـ image

```
COPY target/app.jar app.jar
```
---
## 5) ما وظيفة WORKDIR؟

يحدد الفولدر اللي هيشتغل فيه Docker

```
WORKDIR /app
```

## 🟢 س2:

إيه اللي يحصل لو شلت CMD؟

### الإجابة:

الـ container هيشتغل وبعدين يقف فورًا لأنه مفيش process شغال.


```Dockerfile
FROM java17 image
WORKDIR /app
COPY target/serive.jar service.jar
EXPOSE 9090 
CMD ["java","-jar","service.jar"]
```


the container is an isolated environment
> **If you don’t COPY it, it doesn’t exist inside the container.**


- COPY = ينقل الملفات للـ container
- CMD = يشغل الملف داخل الـ container
- بدون COPY → مفيش ملف → التطبيق يفشل
