## 📄 CV Building — القواعد الأساسية

### 1. الترتيب الصح للـ Sections

```
1. Contact Info
2. Professional Summary
3. Technical Skills
4. Projects / Experience
5. Education
6. Internships & Training
7. Languages
```

> الأهم دايماً فوق — الـ recruiter بيقرأ أول 10 ثواني

### 2. الـ Professional Summary

- **3-4 سطور بس**
- فيها: تخصصك + سنين خبرة + أهم تقنية + قيمتك
- **لا** تكتب "I am hardworking" — ده كلام فاضي
- ✅ مثال جيد:

> "Full-Stack Engineer with hands-on experience in Java Spring Boot and Angular, focused on building scalable REST APIs with clean architecture. Passionate about backend security and real-world production systems."

### 3. الـ Technical Skills

- **دايماً keywords مباشرة** — مش جمل
- رتّبها من الأهم للأقل أهمية
- **لا** تحط skills مش بتعرفها فعلاً — هتتسأل عنها في الإنترفيو
- **لا** تحط soft skills هنا (زي communication) — ليها section تاني

### 4. الـ Projects

- كل project فيه **3 عناصر:**
    - إيه اللي عملته (Action verb)
    - إزاي عملته (التقنيات)
    - نتيجة إيه (Impact)
- ✅ مثال:

> "Built a RESTful e-commerce API using Spring Boot and MySQL, implementing Clean Architecture and JWT authentication to support 5+ product modules."

- حط **GitHub link** دايماً
- **لا** تكتب "simple project" أو "basic app"

### 5. الـ Education

- GPA لو 3.0+ حطها، لو أقل متحطهاش
- ITI وأي training مهمة — حطهم هنا أو في Internships

### 6. الـ Languages

- متحطش ratings بالدوائر أو النجوم — ATS مش بيقراها
- استخدم كلمات: Native / Fluent / Professional / Basic

### 7. أشياء تشيلها نهائياً

- ❌ تاريخ الميلاد
- ❌ الصورة الشخصية (في السيرة الغربية)
- ❌ الحالة الاجتماعية
- ❌ الجنسية (إلا لو مطلوبة)
- ❌ Military Status
- ❌ "References available upon request"

## 🎯 ATS — قواعد لازم تعرفها

### 8. إيه هو ATS؟

نظام بيفلتر السير قبل ما الـ recruiter يشوفها — بيدور على **keywords** من الـ job description

### 9. ATS Killers — حاجات بتخلي السيرة تتفلتر

- ❌ جداول وأعمدة معقدة
- ❌ Icons وصور
- ❌ دوائر تقييم اللغات/الـ skills
- ❌ Header أو Footer فيه معلومات مهمة
- ❌ ملف صورة بدل PDF/Word
- ❌ Font غريبة أو غير standard

### 10. ATS Boosters

- ✅ Keywords من الـ job description بالظبط
- ✅ Section headers واضحة وستاندرد
- ✅ Font بسيطة: Calibri / Arial / Times New Roman
- ✅ حفظ كـ **.docx أو PDF نصي** (مش scanned)
- ✅ bullet points بسيطة

## ✂️ Tailoring — خطوات عملية

### 11. الخطوات الـ 5

```
1. اقرأ الـ job description أكثر من مرة
2. استخرج الـ keywords (تقنيات + soft skills + مسميات)
3. عدّل الـ Summary إنها تعكس الوظيفة
4. رتّب الـ Skills — اللي بيطلبوه يجي أول
5. عدّل وصف الـ Projects يبرز اللي هم محتاجينه
```

### 12. مثال Keywords

لو الـ JD قالت:

> "Spring Boot, microservices, Docker, REST APIs, Agile"

لازم الكلمات دي تظهر **بالظبط** في سيرتك

### 13. الـ Summary بتتغير لكل وظيفة

- وظيفة Backend → ابدأ بـ "Backend Engineer specializing in..."
- وظيفة Full Stack → ابدأ بـ "Full-Stack Developer with expertise in..."
- وظيفة مع Angular → اذكر Angular في أول جملة

### 14. الـ Projects رتّبها حسب الوظيفة

- لو الوظيفة Laravel → الـ Job Board يجي أول
- لو الوظيفة Spring Boot → الـ Dream Shops يجي أول

## 📏 قواعد عامة للشكل

### 15. الطول

- **صفحة واحدة** لو خبرتك أقل من 3 سنين
- صفحتين بس لو عندك خبرة كتير

### 16. الـ Font والـ Size

- Font: Calibri أو Arial
- الاسم: 28-32pt
- العناوين: 12-13pt bold
- المحتوى: 10-11pt

### 17. الـ Action Verbs — ابدأ بيها دايماً

بدل "I worked on" أو "Responsible for":

> Built / Designed / Implemented / Developed / Optimized / Integrated / Deployed / Managed / Led / Created

### 18. الـ Consistency

- التواريخ بنفس الفورمات: `Jan 2023 – Aug 2023`
- الـ bullet points كلها بنفس الأسلوب
- Capital letters ثابتة
