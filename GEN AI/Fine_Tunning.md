# Fine-Tuning

## 1️⃣ ما هو Fine-Tuning ؟

**Fine-Tuning** هو عملية **إعادة تدريب نموذج ذكاء اصطناعي جاهز على بيانات خاصة بك** ليصبح أفضل في تنفيذ مهمة محددة.

بمعنى آخر:

> نأخذ Model مدرب مسبقًا (Pretrained Model) ونعلمه أسلوب أو مهمة معينة باستخدام بياناتنا.

الموديلات الكبيرة مثل التي تطورها OpenAI أو Google تكون مدربة على **كمية ضخمة من البيانات العامة**، لكنها ليست متخصصة في كل شيء.

لذلك نقوم بعمل **Fine-Tuning** حتى يصبح النموذج:

- يفهم بياناتنا الخاصة
    
- يرد بأسلوب محدد
    
- ينفذ مهمة معينة بدقة أعلى
    

---

# 2️⃣ لماذا نستخدم Fine-Tuning ؟

الموديل الأساسي يكون **General Purpose** (عام).

لكن في التطبيقات الحقيقية نحتاج أن يكون:

- متخصص
    
- دقيق
    
- يلتزم بنمط معين من الإجابات
    

مثال:

موديل عام:

```
User: ما هي سياسة الاسترجاع؟
Assistant: تختلف سياسة الاسترجاع حسب الشركة.
```

بعد Fine-Tuning:

```
User: ما هي سياسة الاسترجاع؟
Assistant: يمكن استرجاع المنتج خلال 14 يوم من تاريخ الشراء.
```

أي أن الموديل تعلم **سياسة الشركة**.

---

# 3️⃣ فكرة Fine-Tuning ببساطة

تخيل المثال التالي:

طالب في كلية الطب → هذا مثل **Pretrained Model**

بعد ذلك يتخصص في:

- جراحة القلب
    
- المخ والأعصاب
    
- الأطفال
    

هذا التخصص يشبه **Fine-Tuning**.

```
Model عام  →  تدريب إضافي ببيانات خاصة  →  Model متخصص
```

---

# 4️⃣ ما الذي يحدث أثناء Fine-Tuning ؟

العملية تكون كالتالي:

1️⃣ اختيار Model أساسي  
2️⃣ تجهيز بيانات التدريب  
3️⃣ رفع البيانات  
4️⃣ تدريب النموذج  
5️⃣ الحصول على Model جديد

النتيجة:

```
Original Model
      ↓
Fine-Tuning Training
      ↓
Custom Model
```

---

# 5️⃣ شكل بيانات التدريب

بيانات التدريب تكون في ملف:

```
.jsonl
```

كل سطر يمثل **محادثة تدريبية**.

مثال:

```
{"messages":[
{"role":"user","content":"ما هي عاصمة مصر"},
{"role":"assistant","content":"القاهرة"}
]}
```

مثال آخر:

```
{"messages":[
{"role":"user","content":"صنف هذه الرسالة: المنتج وصل متأخر"},
{"role":"assistant","content":"Complaint"}
]}
```

كلما زادت البيانات **تحسن أداء النموذج**.

---

# 6️⃣ خطوات عمل Fine-Tuning

## 1️⃣ تجهيز البيانات

نكتب البيانات في ملف:

```
training_data.jsonl
```

---

## 2️⃣ رفع الملف إلى API

يتم رفع الملف إلى منصة الذكاء الاصطناعي.

مثال باستخدام API:

```
POST /files
```

---

## 3️⃣ بدء التدريب

بعد رفع الملف نبدأ عملية التدريب:

```
POST /fine_tuning/jobs
```

نحدد:

- الموديل الأساسي
    
- ملف التدريب
    

---

## 4️⃣ انتظار انتهاء التدريب

الحالة تكون:

```
running
```

بعد الانتهاء تصبح:

```
succeeded
```

---

## 5️⃣ الحصول على اسم الموديل

سيتم إنشاء موديل جديد مثل:

```
ft:gpt-4o-mini:custom-model
```

هذا هو **الموديل الخاص بك**.

---

# 7️⃣ استخدام الموديل بعد التدريب

بعد انتهاء Fine-Tuning يمكن استخدام الموديل مثل أي موديل آخر.

مثال API:

```
POST /chat/completions
```

Body:

```json
{
 "model": "ft:your-model",
 "messages":[
  {"role":"user","content":"سؤالك هنا"}
 ]
}
```

الموديل سيجيب **بناءً على البيانات التي دربته عليها**.

---

# 8️⃣ أين يستخدم Fine-Tuning ؟

يستخدم في العديد من التطبيقات:

## 1️⃣ Chatbots

بوت يرد على العملاء بأسلوب الشركة.

مثال:

- دعم فني
    
- خدمة عملاء
    
- مساعد موقع
    

---

## 2️⃣ Text Classification

تصنيف النصوص مثل:

```
رسالة → شكوى
رسالة → سؤال
رسالة → طلب
```

---

## 3️⃣ Data Extraction

تحويل النص إلى بيانات منظمة.

مثال:

النص:

```
اشتريت لابتوب ب 15000 جنيه
```

النتيجة:

```
{
 "product":"laptop",
 "price":15000
}
```

---

## 4️⃣ Content Generation

إنشاء محتوى بأسلوب معين مثل:

- كتابة وصف المنتجات
    
- الردود التلقائية
    

---

# 9️⃣ متى لا نستخدم Fine-Tuning ؟

لا نستخدم Fine-Tuning عندما نريد:

- تحديث معلومات الموديل باستمرار
    
- استخدام قاعدة بيانات كبيرة
    

في هذه الحالة نستخدم تقنية أخرى تسمى **RAG (Retrieval Augmented Generation)**.

---

# 🔟 فوائد Fine-Tuning

فوائده:

- دقة أعلى
    
- أسلوب ثابت في الرد
    
- أداء أفضل في المهام المتخصصة
    
- تقليل حجم الـ prompts
    

---

# 11️⃣ مثال تطبيقي بسيط

تريد عمل Chatbot لموقع خدمات.

تقوم بتدريب الموديل على:

- الأسئلة الشائعة
    
- سياسات الموقع
    
- طريقة الرد
    

بعد التدريب:

المستخدم يسأل:

```
كم مدة التوصيل؟
```

الموديل يجيب:

```
مدة التوصيل من 2 إلى 4 أيام عمل.
```
