الأسئلة اللي بتيجي في أي انترفيو Java Spring Boot بتتقسم كده:

---

**١. Java Core**

- OOP (Inheritance, Polymorphism, Encapsulation, Abstraction)
- Collections Framework (List, Map, Set)
- Exception Handling
- Generics
- Multithreading & Concurrency
- Java 8+ Features (Lambdas, Streams, Optional)

---

**٢. Spring Core**

- Dependency Injection & IoC Container
- Bean Lifecycle
- Annotations زي `@Component`, `@Autowired`, `@Bean`
- ApplicationContext vs BeanFactory

---

**٣. Spring Boot**

- Auto Configuration إزاي بتشتغل
- `application.properties` vs `application.yml`
- Profiles (dev, prod)
- Actuator

---

**٤. Spring MVC & REST**

- `@RestController`, `@RequestMapping`, `@PathVariable`, `@RequestBody`
- HTTP Methods (GET, POST, PUT, DELETE)
- Exception Handling في REST (`@ControllerAdvice`)

---

**٥. Spring Data JPA**

- Entity, Repository
- Relationships (OneToMany, ManyToMany)
- JPQL vs Native Query
- Lazy vs Eager Loading

---

**٦. Spring Security**

- Authentication vs Authorization
- JWT Token
- `@PreAuthorize`

---

**٧. Database**

- SQL Joins
- Transactions (`@Transactional`)
- Indexing

---

**٨. General**

- Design Patterns (Singleton, Factory, Builder)
- SOLID Principles
- Microservices basics
