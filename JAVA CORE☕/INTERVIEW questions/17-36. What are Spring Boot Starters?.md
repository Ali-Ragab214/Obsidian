
# 36. ما هي Spring Boot Starters؟

## ما المقصود بـ Spring Boot Starters؟

الـ **Spring Boot Starters** هي عبارة عن **حزم Dependencies جاهزة ومُعدّة مسبقًا** يوفرها Spring Boot لتسهيل إنشاء المشاريع.

بدلًا من أن تقوم بإضافة عشرات الـ Dependencies يدويًا، كل ما عليك هو إضافة **Starter واحدة**، وسيقوم Spring Boot بإضافة كل المكتبات اللازمة لهذه الوظيفة تلقائيًا.

بمعنى آخر:

> **Starter = مجموعة Dependencies مرتبطة بوظيفة معينة تم تجميعها في Dependency واحدة.**

---
starter => collection of related dependencies 
## Quick Revision (احفظهم)

- **What is a Starter?**
    
    > A pre-packaged dependency for a specific feature.
    
- **Why use it?**
    
    > To simplify dependency management.
    
- **Example?**
    
    > `spring-boot-starter-web`.
    
- **Business logic?**
    
    > No.
    
- **Multiple Starters?**
    
    > Yes.
    
- **Versions managed by?**
    
    > `spring-boot-starter-parent`.
## لماذا تم إنشاء الـ Starters؟

قبل ظهور Spring Boot، إذا أردت إنشاء Web Application أو REST API، كنت تحتاج لإضافة العديد من المكتبات بنفسك.

مثلاً لإنشاء REST API كنت تحتاج إلى:

- Spring MVC
    
- Jackson لتحويل JSON
    
- Embedded Tomcat
    
- Validation
    
- Logging
    
- Spring Core
    
- Spring Beans
    
- وغيرها...
    

وكان عليك أن:

- تبحث عن كل Dependency بنفسك.
    
- تختار النسخ المتوافقة.
    
- تحل مشاكل تعارض الإصدارات (Dependency Conflicts).
    

وكان هذا الأمر مرهقًا جدًا.

لذلك جاءت فكرة الـ Starters.

---

# قبل الـ Starters

كان ملف `pom.xml` يبدو هكذا:

```xml
<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-webmvc</artifactId>
</dependency>

<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
</dependency>

<dependency>
    <groupId>org.apache.tomcat.embed</groupId>
    <artifactId>tomcat-embed-core</artifactId>
</dependency>

<dependency>
    <groupId>org.hibernate.validator</groupId>
    <artifactId>hibernate-validator</artifactId>
</dependency>

<!-- Dependencies أخرى -->
```

أي أنك كنت تضيف كل شيء بنفسك.

---

# بعد الـ Starters

يكفي أن تكتب:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

وسيقوم Spring Boot بإضافة كل ما تحتاجه تلقائيًا.

---

# كيف تعمل الـ Starters؟

الـ Starter نفسها غالبًا لا تحتوي على كود مهم.

هي تعمل كـ:

> **Dependency Aggregator**

أي "مجمّع Dependencies".

مثال:

```text
spring-boot-starter-web
            ↓
    Spring MVC->library
    Jackson
    Embedded Tomcat
    Validation
    Logging
    Spring Core
```

أي أنك تحصل على كل هذه المكتبات بإضافة Dependency واحدة فقط.

---

# ما دور spring-boot-starter-parent ؟

غالبًا يبدأ مشروع Spring Boot بهذا الشكل:

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.x.x</version>
</parent>
```

مثال:

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.5.3</version>
</parent>
```

وظيفته:

- إدارة إصدارات الـ Dependencies.
    
- إدارة إصدارات الـ Plugins.
    
- التأكد من توافق جميع المكتبات مع بعضها.
    

لذلك لا نكتب Version لمعظم الـ Starters.

مثال:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

لاحظ عدم وجود:

```xml
<version>...</version>
```

# أشهر Spring Boot Starters

## 1) spring-boot-starter-web

تُستخدم لإنشاء:

- REST APIs
    
- Web Applications
    
- Microservices
    

### إضافتها:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

### تحتوي على:

- Spring MVC
    
- Jackson
    
- Embedded Tomcat
    
- Validation
    
- Logging
    

### مثال:

```java
@RestController
@RequestMapping("/users")
public class UserController {

    @GetMapping
    public String hello() {
        return "Hello";
    }
}
```

---

## 2) spring-boot-starter-data-jpa

تُستخدم للتعامل مع قواعد البيانات باستخدام JPA.

### إضافتها:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

### تحتوي على:

- Spring Data JPA
    
- Hibernate
    
- Spring JDBC
    
- Transaction Management
    

### مثال:

```java
@Entity
public class User {

    @Id
    @GeneratedValue
    private Long id;

    private String name;
}
```

Repository:

```java
public interface UserRepository extends JpaRepository<User, Long> {

}
```

---

## 3) spring-boot-starter-security

تُستخدم من أجل:

- Authentication
    
- Authorization
    
- حماية الـ APIs
    

### إضافتها:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
```

### ماذا يحدث بمجرد إضافتها؟

- تصبح جميع الـ Endpoints محمية تلقائيًا.
    
- يتم إنشاء Username وPassword مؤقتين.
    

مثال:

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

}
```

---

## 4) spring-boot-starter-validation

تُستخدم للتحقق من صحة البيانات القادمة من المستخدم.

### إضافتها:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```

### مثال:

DTO:

```java
public class UserRequest {

    @NotBlank
    private String name;

    @Email
    private String email;
}
```

Controller:

```java
@PostMapping
public ResponseEntity<?> save(@Valid @RequestBody UserRequest request) {
    return ResponseEntity.ok().build();
}
```

إذا أرسل المستخدم Email غير صحيح، سيمنع Spring الطلب تلقائيًا.

## 6) spring-boot-starter-actuator

تُستخدم لمراقبة التطبيق وإدارته.

### إضافتها:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```

### توفر Endpoints مثل:

```text
/actuator/health
/actuator/info
/actuator/metrics
/actuator/env
```

مثال:

```properties
management.endpoints.web.exposure.include=*
```

ثم:

```http
GET /actuator/health
```

النتيجة:

```json
{
    "status": "UP"
}
```

# مثال عملي لمشروع حقيقي

لنفترض أنك تبني API لموقع توظيف.

ستحتاج إلى:

- إنشاء REST API.
    
- التعامل مع قاعدة البيانات.
    
- تسجيل الدخول.
    
- التحقق من البيانات.
    

إذًا ستستخدم:

```xml
<dependencies>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-data-jpa</artifactId>
    </dependency>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-security</artifactId>
    </dependency>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-validation</artifactId>
    </dependency>

</dependencies>
```

وخلال دقائق يصبح لديك مشروع جاهز للعمل.

# كيف أعرف ماذا تحتوي الـ Starter؟

استخدم الأمر:

```bash
mvn dependency:tree
```

سيظهر شيء مشابه لهذا:

```text
spring-boot-starter-web
├── spring-webmvc
├── spring-boot-starter-json
├── spring-boot-starter-tomcat
└── spring-boot-starter
```

وبذلك تستطيع معرفة جميع الـ Dependencies التي تم إضافتها تلقائيًا.

# مميزات Spring Boot Starters
Spring Boot Starters are ready-made dependency packages that simplify project setup by grouping related dependencies together.

### 1. تسهيل إدارة الـ Dependencies

Dependency واحدة بدل عشرات.

---

### 2. منع تعارض الإصدارات

Spring Boot يختار نسخًا متوافقة مع بعضها.

---

### 3. تسريع التطوير

يمكنك بدء المشروع بسرعة كبيرة.

---

### 4. تقليل الـ Boilerplate

لن تحتاج لإعداد كل شيء يدويًا.

---

### 5. إعدادات افتراضية جاهزة

توفر إعدادات مناسبة لمعظم الحالات.

# أسئلة إنترفيو

### ما هي Spring Boot Starter؟

هي Dependency جاهزة تجمع مجموعة من المكتبات اللازمة لوظيفة معينة داخل Spring Boot.

---

### هل تحتوي الـ Starters على Business Logic؟

لا.

هي مجرد مجمعات Dependencies.

---

### لماذا لا نكتب Version مع الـ Starter؟

لأن `spring-boot-starter-parent` يدير الإصدارات تلقائيًا.

---

### هل يمكن استخدام أكثر من Starter في نفس المشروع؟

نعم، وهذا ما يحدث في معظم المشاريع الحقيقية.

---

### كيف تعرف المكتبات الموجودة داخل Starter معينة؟

باستخدام:

```bash
mvn dependency:tree
mvn dependency:tree
```

# ملخص سريع

> تخيل أن Spring Boot Starter مثل "علبة أدوات جاهزة".

إذا كنت تريد بناء REST API، بدل أن تشتري كل أداة وحدها، تشتري علبة اسمها:

```text
spring-boot-starter-web
```

فتجد بداخلها كل الأدوات التي تحتاجها (Tomcat، Jackson، Spring MVC، Logging...) وتكون متوافقة مع بعضها وجاهزة للاستخدام. وهذا هو السبب الرئيسي الذي جعل Spring Boot أسرع وأسهل بكثير من Spring التقليدي.
