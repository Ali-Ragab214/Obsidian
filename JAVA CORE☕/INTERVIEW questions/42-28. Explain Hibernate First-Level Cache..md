# Interview Summary

**ما هو Hibernate First-Level Cache؟**

> هو Cache داخلي موجود افتراضياً داخل Hibernate، مرتبط بالـ `EntityManager` أو الـ `Session`. عند قراءة Entity لأول مرة من قاعدة البيانات، يتم تخزينها داخل الـ Persistence Context. أي طلب لاحق لنفس الـ Entity داخل نفس الـ Session يتم إرجاعه من الـ Cache بدلاً من تنفيذ Query جديدة، مما يحسن الأداء ويقلل عدد الاستعلامات. يتم حذف هذا الـ Cache بمجرد انتهاء الـ Session.
