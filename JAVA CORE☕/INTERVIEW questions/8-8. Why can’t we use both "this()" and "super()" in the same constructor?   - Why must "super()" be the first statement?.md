

`this()` و `super()` هما special constructor calls في Java.

- `this()` → تستدعي Constructor آخر داخل نفس الـ class.
    
- `super()` → تستدعي Constructor الـ Parent class.
    

---

# Why can’t we use both `this()` and `super()` in the same constructor?

لأن:

# الاتنين لازم يكونوا أول statement داخل الـ constructor.

---

# مثال ❌

```java
class Person {

    public Person() {
        System.out.println("Person Constructor");
    }
}
```

---

```java
class Student extends Person {

    public Student() {

        this("Ali");

        super(); // ❌ Compile Error
    }

    public Student(String name) {
        System.out.println(name);
    }
}
```

---

# ليه Error؟

لأن:

```java
this("Ali");
```

لازم تكون أول سطر.

وفي نفس الوقت:

```java
super();
```

لازم تكون أول سطر برضه.

وده مستحيل.

---

# Java بتمنع ده ليه؟

عشان تمنع:

- constructor confusion
    
- initialization problems
    
- constructor loops
    

---

# Constructor Chaining in Java

لما object يتعمل، Java عندها ترتيب ثابت:

```text
Parent Constructor
        ↓
Child Constructor
```

---

# لو استخدمت `this()`

Java تقول:

```text
روح الأول لـ constructor تاني داخل نفس الكلاس
```

---

# ولو استخدمت `super()`

Java تقول:

```text
روح الأول لـ constructor الأب
```

---

# مين يشتغل الأول؟

هيحصل تعارض.

لذلك:

# لا يمكن استخدام `this()` و `super()` معًا داخل نفس constructor.

---

# Why must `super()` be the first statement?

لأن:

# الـ Parent class لازم يتهيأ الأول قبل الـ Child class.

---

# مثال

```java
class Person {

    protected String name;

    public Person(String name) {

        this.name = name;

        System.out.println("Person Constructor");
    }
}
```

---

```java
class Student extends Person {

    private int age;

    public Student(String name, int age) {

        super(name);

        this.age = age;

        System.out.println("Student Constructor");
    }
}
```

---

# ترتيب التنفيذ

```java
new Student("Ali", 22);
```

يحصل:

```text
1. تشغيل Constructor الأب
2. تهيئة fields الأب
3. الرجوع للابن
4. تشغيل Constructor الابن
5. تهيئة fields الابن
```

---

# ليه لازم الأب يشتغل الأول؟

لأن:

# الابن يعتمد على الأب.

فالجزء الخاص بالأب لازم يتبني الأول.

---

# ماذا يحدث لو لم نكتب `super()` ؟

Java تضيف تلقائيًا:

```java
super();
```

---

# لكن بشرط

إن الـ Parent class يحتوي على constructor فارغ.

---

# مثال ❌

```java
class Person {

    public Person(String name) {

    }
}
```

---

```java
class Student extends Person {

    public Student() {

    }
}
```

---

# هنا Compile Error

لأن Java حاولت تعمل:

```java
super();
```

لكن:

# لا يوجد constructor فارغ داخل Person.

---

# الحل

```java
public Student() {

    super("Ali");
}
```

---

# الخلاصة

|Concept|Explanation|
|---|---|
|`this()`|Calls another constructor in the same class|
|`super()`|Calls parent constructor|
|Why not both?|Both must be the first statement|
|Why `super()` first?|Parent must initialize before child|
|What if we don’t write it?|Java inserts `super()` automatically|
