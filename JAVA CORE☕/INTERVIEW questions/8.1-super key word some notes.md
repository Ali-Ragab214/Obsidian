package org.example;

        this.behavior = behavior;

لأن `super` ليها **قواعد محددة** في Java:

---

**`super` بتستخدمها في 3 أماكن بس:**

```java
// 1. في الـ Constructor - أول سطر بالظبط
ALi(String name, int b, String tall) {
    super(name, b);  // ✅ لازم أول سطر
    this.tall = tall;
}

// 2. جوّا Method - تكلم method الـ Parent
void display() {
    super.display();  // ✅ 
}

// 3. جوّا Method - تاخد field من الـ Parent
void display() {
    System.out.println(super.name);  // ✅
}
```

---

**ليه مينفعش برّا؟**

لأن `super` مش object مستقل تقدر تمسكه أو تحطه في متغير — هي بس **keyword** بتقول لـ Java:

> "روح جيب الحاجة دي من الـ Parent Class بتاعي" 

ومعناها مرتبط بـ **السياق الداخلي** للـ Class نفسه — برّا الـ Class مفيش "Parent" تروحله.

```java
// برّا الـ Class - مينفعش ❌
Ragab r = super; // Error - super مش object
super.display(); // Error - إنت فين بالظبط عشان تقول "parent بتاعي"؟
```

---

**الخلاصة:**

`super` مش object — هي keyword بتشتغل بس **جوّا الـ Subclass** في Constructor أو Method.
