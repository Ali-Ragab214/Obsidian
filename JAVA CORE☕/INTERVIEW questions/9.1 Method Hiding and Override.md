## Method Hiding — الملخص الكامل

---

### إيه هو؟

لما الـ Child Class بيعرّف `static method` بنفس اسم الـ Parent — ده مش Override، ده **Method Hiding**.

---

### القاعدة الأساسية

```
Static Method  → بيتبع الـ Reference Type  (Compile Time)
Instance Method → بيتبع الـ Object الفعلي  (Runtime)
```

---

### الحالات الأربعة

```java
Animal a = new Dog();
a.sound();        // Animal sound ← Reference = Animal

Dog d = new Dog();
d.sound();        // Dog sound    ← Reference = Dog

Animal.sound();   // Animal sound ← ✅ Best Practice
Dog.sound();      // Dog sound    ← ✅ Best Practice
```

---

### Override vs Method Hiding

||Override|Method Hiding|
|---|---|---|
|**نوع الـ Method**|Instance|Static|
|**بيتبع إيه؟**|الـ Object|الـ Reference|
|**القرار امتى؟**|Runtime|Compile Time|
|**`@Override`**|✅|❌ Compile Error|

---

### الطريقة الصح للاستدعاء

```java
// ⚠️ بيشتغل بس Warning
a.sound();
d.sound();

// ✅ Best Practice دايماً
Animal.sound();
Dog.sound();
```

---

> 💡 **جملة تقولها في الـ Interview:** "Static methods can't be overridden — instead they get hidden. The key difference is that hiding follows the **Reference Type** at Compile Time, while Override follows the **actual Object** at Runtime."
