شكل ده Interview آلي (AI-powered) هيسألك على 4 محاور رئيسية زي ما ظاهر في الصورة. خليني أوضحلك كل محور هيتغطى فيه إيه بالظبط، عشان تعرف تركز مذاكرتك فين:

## 1️⃣ Java Backend Development (Enterprise-grade)

مش أسئلة Java أساسية بس، غالبًا هيسألوا على:

- Collections Framework (زي اللي احنا اتكلمنا عليه: Array, List, Map, Set) وأداءها.
- Multithreading & Concurrency (Thread pools, synchronized, ExecutorService, CompletableFuture).
- Exception Handling وCustom Exceptions.
- Java Memory Model (Heap, Stack, Garbage Collection).
- Design Patterns (Singleton, Factory, Builder, Strategy) في سياق Enterprise apps.
- Java 8+ features (Streams, Lambda, Optional).

## 2️⃣ Spring Ecosystem (Spring Framework / Spring Boot)

- Dependency Injection & IoC Container.
- Spring Boot Auto-configuration وإزاي بتشتغل من جوه.
- Spring Data JPA (Repositories, Entity relationships, Lazy vs Eager loading).
- Spring Security (Authentication, Authorization, JWT).
- Transaction Management (`@Transactional`, Propagation, Isolation levels).
- Spring AOP و Advisors (زي اللي اتكلمنا عليه).
- Bean Lifecycle & Scopes.

## 3️⃣ RESTful API Design & Microservices Architecture

- REST principles (Idempotency, Statelessness, HTTP methods/status codes صح).
- API Versioning strategies.
- Microservices communication (Sync via REST/Feign vs Async via Kafka/RabbitMQ).
- Service Discovery (Eureka), API Gateway، Circuit Breaker (Resilience4j/Hystrix).
- Database per Service pattern، Saga pattern للـ distributed transactions.
- API Security (OAuth2, Rate Limiting).

## 4️⃣ Performance Tuning & Optimization (High-traffic systems)

- Caching strategies (Redis, Spring Cache, Cache eviction policies).
- Database query optimization (Indexing, N+1 problem, Connection pooling).
- JVM Tuning (GC tuning, Heap sizing).
- Load Balancing & Horizontal Scaling.
- Async processing وMessage Queues لتخفيف الحمل.
- Monitoring & Profiling (زي Micrometer, Prometheus, JProfiler).
