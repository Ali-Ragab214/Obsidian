
 

## هو إيه؟

ببساطة: **قالب جاهز** بيعمل لك هيكل المشروع تلقائياً

---

## مثال توضيحي

بدل ما تعمل الفولدرات دي بإيدك:

```
my-app/
├── src/
│   ├── main/
│   │   └── java/
│   └── test/
│       └── java/
└── pom.xml
```

**Archetype بيعملها لك في ثانية** ✅

---

## اللي محتاج تعرفه بس 🎯

### الأمر الوحيد المهم

```bash
mvn archetype:generate
```

أو أسهل من الـ **IDE بـ clicks**

### أشهر Archetype هتستخدمه

```
maven-archetype-quickstart
```

ده بيعمل مشروع Java عادي جاهز على طول

---

## في الـ IDE بقى 😄

> بصراحة 99% من الوقت مش هتكتب أمر، هتعمل: **New Project → Maven → Archetype → Quickstart → خلاص** 🎉

---

## الخلاصة في جملة واحدة

> Archetype = **Template جاهز** بيوفر عليك تعمل هيكل المشروع بإيدك، وكل اللي محتاج تعرفه هو إن الـ **quickstart** هو اللي هتستخدمه دايماً 💪
