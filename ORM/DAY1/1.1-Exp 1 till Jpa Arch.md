# أولًا: What is JDBC?

## يعني إيه JDBC؟

JDBC اختصار لـ

> **Java Database Connectivity**

وهو الـ API اللي بيسمح لتطبيق Java إنه يتكلم مع قاعدة البيانات.

بمعنى:

```text
Java Application
        │
      JDBC
        │
Database Driver
        │
   PostgreSQL
```

يعني الـ JDBC مجرد وسيط.

---

## خطوات التعامل باستخدام JDBC

لو هتجيب User من قاعدة البيانات هتعمل:

```java
Connection connection = DriverManager.getConnection(...);

PreparedStatement ps =
connection.prepareStatement(
"select * from users where id=?");

ps.setInt(1,1);

ResultSet rs = ps.executeQuery();
```

بعدها

```java
while(rs.next()){

User user = new User();

user.setName(rs.getString("name"));

user.setEmail(rs.getString("email"));

}
```

وأخيرًا

```java
rs.close();

ps.close();

connection.close();
```

# أهم أسئلة الانترفيو

1. **What is JDBC?**  
    واجهة (API) في Java للتعامل مع قواعد البيانات.
    
2. **What is ORM?**  
    تقنية لعمل Mapping بين Java Objects وجداول قواعد البيانات.
    
3. **Why do we use ORM?**  
    لتقليل كتابة SQL وعمليات الـ Mapping اليدوية، وتحسين قابلية الصيانة.
    
4. **Which is faster: JDBC or ORM?**  
    JDBC أسرع في الأداء الخام، لكن ORM أكثر إنتاجية وأسهل في التطوير والصيانة.
    
5. **Is JPA a Framework?**  
    لا، هي Specification.
    
6. **What is Hibernate?**  
    أشهر ORM Framework في Java، وهو Implementation لـ JPA.

# IMPORTANT
1. **Does Hibernate replace JDBC?**   # 
    لا، Hibernate يعتمد على JDBC في النهاية للتواصل مع قاعدة البيانات.
