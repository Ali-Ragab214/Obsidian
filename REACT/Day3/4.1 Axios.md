بص يا علي، بما إنك بدأت React بجد، فـ **Axios** من أهم الحاجات اللي هتستخدمها تقريبًا في أي مشروع بيتعامل مع API.

هشرحها لك من الصفر لحد الطريقة اللي الشركات بتستخدمها.

---

# أولاً: Axios يعني إيه؟

Axios هي Library في React (وفي JavaScript عمومًا) بتستخدمها علشان تبعت HTTP Requests للـ API.

يعني بدل ما تعمل:

```text
Frontend  -----> API -----> Database
```

Axios هي اللي بتنفذ الجزء ده.

تقدر بيها تعمل:

- GET → تجيب بيانات
    
- POST → تبعت بيانات
    
- PUT → تعدل بيانات
    
- PATCH → تعديل جزئي
    
- DELETE → تحذف بيانات
    

---

# طب React مش فيها fetch أصلاً؟

آه.

JavaScript نفسها فيها:

```js
fetch()
```

فالسؤال:

> ليه أستخدم Axios طالما فيه Fetch؟

---

# Fetch

مثال:

```js
const response = await fetch(
    "https://jsonplaceholder.typicode.com/users"
);

const data = await response.json();

console.log(data);
```

---

# Axios

نفس المثال:

```js
const response = await axios.get(
    "https://jsonplaceholder.typicode.com/users"
);

console.log(response.data);
```

---

# الفرق بينهم

## 1) تحويل JSON

### Fetch

لازم تعمل:

```js
const response = await fetch(url);

const data = await response.json();
```

### Axios

بيعملها لوحده:

```js
const response = await axios.get(url);

response.data
```

أسهل.

---

## 2) التعامل مع الأخطاء

### Fetch

Fetch بيعتبر إن أي Response وصل = نجاح.

حتى لو السيرفر رجع:

```text
404
500
401
```

مش هيرمي Error.

لازم تعمل:

```js
if(!response.ok){
    throw new Error("Error");
}
```

---

### Axios

بيرمي Error تلقائي.

مثلاً:

```js
try {
    await axios.get(url);
}
catch(error){
    console.log(error);
}
```

لو API رجعت 404 أو 500 هيدخل على catch مباشرة.

وده مريح جدًا.

---

## 3) Interceptors

دي من أقوى مميزات Axios.

تقدر تقول له:

> قبل أي Request حط الـ Token.

بدل ما تكرر ده في كل مكان.

هنشوفها بعد شوية.

---

## 4) Timeout

Axios:

```js
axios.get(url,{
    timeout:5000
})
```

Fetch محتاجة شغل زيادة.

---

## 5) Request/Response Transformation

Axios أسهل في تعديل الـ Requests والـ Responses.

# استخدامها داخل useEffect

وده الأكثر شيوعًا.

```jsx
import { useEffect, useState } from "react";
import axios from "axios";

export default function Users(){

    const [users,setUsers] = useState([]);

    useEffect(() => {

        async function fetchUsers(){

            try{

                const response = await axios.get(
                    "https://jsonplaceholder.typicode.com/users"
                );

                setUsers(response.data);

            }
            catch(error){
                console.log(error);
            }
        }

        fetchUsers();

    },[]);

    return(
        <>
            {
                users.map(user => (
                    <p key={user.id}>
                        {user.name}
                    </p>
                ))
            }
        </>
    )
}
```

# لو عندك JWT Token

بدل:

```js
headers:{
 Authorization:`Bearer ${token}`
}
```

في كل مرة.

استخدم Interceptor.

---

# Interceptor

```js
api.interceptors.request.use(

    (config)=>{

        const token = localStorage.getItem("token");

        if(token){

            config.headers.Authorization =
                `Bearer ${token}`;
        }

        return config;
    },

    (error)=>{
        return Promise.reject(error);
    }
);
```

---

دلوقتي أي Request:

```js
api.get("/users");
api.post("/posts");
api.delete("/orders");
```

هيضيف الـ Token تلقائيًا.

---

# Response Interceptor

مثلاً لو الـ Token انتهت صلاحيته:

```js
api.interceptors.response.use(

    response => response,

    error => {

        if(error.response?.status === 401){

            localStorage.removeItem("token");

            window.location.href="/login";
        }

        return Promise.reject(error);
    }
);
```

# شكل الخطأ في Axios

```js
catch(error){

    console.log(error.response); // بيانات السيرفر

    console.log(error.response.status);

    console.log(error.response.data);
}
```

مثال:

```js
if(error.response?.status === 404){
    alert("Not Found");
}
```

# Async/Await ولا Then؟

### Then

```js
axios.get("/users")
    .then(response=>{
        console.log(response.data);
    })
    .catch(error=>{
        console.log(error);
    });
```

---

### Async/Await

```js
try{

    const response = await api.get("/users");

    console.log(response.data);

}
catch(error){

    console.log(error);
}
```

وده الأفضل والأكثر استخدامًا لأنه أوضح وأسهل في القراءة.

# ملخص سريع

|الحاجة|Fetch|Axios|
|---|---|---|
|موجودة في JavaScript|✅|❌|
|تحتاج تثبيت|❌|✅|
|تحويل JSON تلقائي|❌|✅|
|يرمي Error لـ 404/500 تلقائيًا|❌|✅|
|Interceptors|❌|✅|
|Timeout سهل|❌|✅|
|سهولة الاستخدام|جيدة|ممتازة|

# لو هتشتغل في مشاريع React حقيقية

الترتيب اللي أنصحك بيه:

1. افهم `fetch`.
    
2. اتعلم `axios`.
    
3. استخدم `axios.create()`.
    
4. اتعلم `Interceptors`.
    
5. اربطها مع Authentication وJWT.
    
6. بعد كده اتعلم أدوات زي React Query أو TanStack Query لأنها بتبني فوق فكرة جلب البيانات بطريقة احترافية جدًا.
    

لو أتقنت الجزء ده، هتكون فاهم 90% من طريقة تعامل تطبيقات React الحقيقية مع الـ APIs.
