
# Destructuring = طريقة سريعة تطلع قيم من **object أو array** وتحطها في variables بسهولة بدل ما تكتب كود طويل.

---

# الفكرة ببساطة

بدل ما تجيب القيم خطوة خطوة…  
تقدر “تفكك” البيانات مرة واحدة.

---

# 1️⃣ Object Destructuring

## بدون destructuring ❌

```js
const user = {
  name: "Ali",
  age: 23,
  city: "Cairo"
}

const name = user.name
const age = user.age
const city = user.city
```

كود طويل وممل 😵‍💫

---

## باستخدام destructuring ✅

```js
const user = {
  name: "Ali",
  age: 23,
  city: "Cairo"
}

const { name, age, city } = user
```

✨ كده React developers بيكتبوا الكود دايماً.

---

# 2️⃣ ليه مهم في React؟

هتشوفه طول الوقت مع **props**

بدل:

```js
function Card(props){
  return <h2>{props.title}</h2>
}
```

نكتب:

```js
function Card({ title }){
  return <h2>{title}</h2>
}
```

---

# 3️⃣ Array Destructuring

## بدون destructuring

```js
const fruits = ["apple", "banana"]

const first = fruits[0]
const second = fruits[1]
```

## باستخدام destructuring

```js
const fruits = ["apple", "banana"]

const [first, second] = fruits
```

---

# 4️⃣ أهم مثال في React 🔥

`useState` نفسه مبني على destructuring:

```js
const [count, setCount] = useState(0)
```

React بيرجع Array:

```js
[ value , function ]
```

وانت بتفكها بـ destructuring.

---

# 5️⃣ تغيير اسم المتغير (مهم)

```js
const user = { name: "Ali" }

const { name: userName } = user
```

بقى اسم المتغير `userName`.
