## `.map()`

> 🔵 **إيه هو؟** بيمر على كل عنصر في الـ array وبيرجع **array جديد** بعد تحويل كل عنصر.

### Syntax

```js
array.map((element, index) => newValue)
```

### مثال بسيط

```js
const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);
console.log(doubled); // [2, 4, 6, 8]

```

### مثال واقعي

```js
const users = ["Ahmed", "Sara", "Ali"];
const greetings = users.map(name => `Hello, ${name}!`);
// ["Hello, Ahmed!", "Hello, Sara!", "Hello, Ali!"]
```

### ⚛️ في React

```jsx
const ProductList = () => {
  const products = [
    { id: 1, name: "Laptop", price: 999 },
    { id: 2, name: "Phone", price: 499 },
    { id: 3, name: "Tablet", price: 299 },
  ];
  

  return (
    <ul>
      {products.map(product => (
        <li key={product.id}>
          {product.name} — ${product.price}
        </li>
      ))}
    </ul>
  );
};
```

> [!warning] مهم جداً لازم تحط `key` على كل عنصر في الـ `.map()` في React

## `.filter()`

> 🟢 **إيه هو؟** بيمر على كل عنصر وبيرجع **array جديد** فيه العناصر اللي الشرط بتاعها `true` بس.

### Syntax

```js
array.filter((element) => condition)
```

### مثال بسيط

```js
const nums = [1, 2, 3, 4, 5, 6];
const evens = nums.filter(n => n % 2 === 0);
console.log(evens); // [2, 4, 6]
```

### مثال واقعي

```js
const products = [
  { name: "Laptop", price: 999 },
  { name: "Phone", price: 499 },
  { name: "Case", price: 19 },
];

const expensive = products.filter(p => p.price > 100);
// [{ name: "Laptop" }, { name: "Phone" }]
```

### ⚛️ في React — حذف task

```jsx
const TodoApp = () => {
  const [tasks, setTasks] = useState([
    { id: 1, text: "Learn React" },
    { id: 2, text: "Build a project" },
    { id: 3, text: "Deploy app" },
  ]);

  const deleteTask = (id) => {
    setTasks(tasks.filter(task => task.id !== id));
  };

  return (
    <ul>
      {tasks.map(task => (
        <li key={task.id}>
          {task.text}
          <button onClick={() => deleteTask(task.id)}>🗑️ Delete</button>
        </li>
      ))}
    </ul>
  );
};
```

## `.find()`

> 🟡 **إيه هو؟** بيرجع **أول عنصر** الشرط بتاعه `true` — مش array، عنصر واحد بس. لو ملقاش حاجة بيرجع `undefined`.

### Syntax

```js
array.find((element) => condition)
```

### مثال بسيط

```js
const nums = [5, 12, 8, 130, 44];
const found = nums.find(n => n > 10);
console.log(found); // 12 (أول واحد أكبر من 10)
```

### مثال واقعي

```js
const users = [
  { id: 1, name: "Ahmed" },
  { id: 2, name: "Sara" },
  { id: 3, name: "Ali" },
];

const user = users.find(u => u.id === 2);
console.log(user); // { id: 2, name: "Sara" }
```

### ⚛️ في React — عرض تفاصيل مستخدم

```jsx
const UserProfile = ({ userId }) => {
  const users = [
    { id: 1, name: "Ahmed", role: "Admin" },
    { id: 2, name: "Sara", role: "User" },
    { id: 3, name: "Ali", role: "Editor" },
  ];

  const user = users.find(u => u.id === userId);

  return (
    <div>
      {user ? (
        <>
          <h2>{user.name}</h2>
          <p>Role: {user.role}</p>
        </>
      ) : (
        <p>User not found ❌</p>
      )}
    </div>
  );
};
```

## `.findIndex()`

> 🟠 **إيه هو؟** زي `.find()` بالظبط بس بيرجع **رقم الـ index** مش العنصر نفسه. لو ملقاش بيرجع `-1`.

### Syntax

```js
array.findIndex((element) => condition)
```

### مثال بسيط

```js
const fruits = ["apple", "banana", "mango"];
const index = fruits.findIndex(f => f === "banana");
console.log(index); // 1
```

### ⚛️ في React — تعديل عنصر في array

```jsx
const TaskApp = () => {
  const [tasks, setTasks] = useState([
    { id: 1, text: "Learn React", done: false },
    { id: 2, text: "Build project", done: false },
  ]);

  const toggleTask = (id) => {
    const index = tasks.findIndex(t => t.id === id);
    const updatedTasks = [...tasks];
    updatedTasks[index] = {
      ...updatedTasks[index],
      done: !updatedTasks[index].done,
    };
    setTasks(updatedTasks);
  };

  return (
    <ul>
      {tasks.map(task => (
        <li
          key={task.id}
          style={{ textDecoration: task.done ? "line-through" : "none" }}
          onClick={() => toggleTask(task.id)}
        >
          {task.text}
        </li>
      ))}
    </ul>
  );
};
```

## `.some()`

> 🔴 **إيه هو؟** بيتحقق لو **عنصر واحد على الأقل** في الـ array شرطه `true` — بيرجع `true` أو `false`.

### Syntax

```js
array.some((element) => condition)
```

### مثال بسيط

```js
const ages = [15, 22, 17, 14];
const hasAdult = ages.some(age => age >= 18);
console.log(hasAdult); // true (22 >= 18)
```

### مثال واقعي

```js
const cart = [
  { name: "Laptop", inStock: true },
  { name: "Phone", inStock: false },
];

const hasOutOfStock = cart.some(item => !item.inStock);
// true — في item واحد مش متاح
```

### ⚛️ في React

```jsx
const CartPage = () => {
  const [cart, setCart] = useState([
    { id: 1, name: "Laptop", inStock: true },
    { id: 2, name: "Rare Item", inStock: false },
  ]);

  const hasOutOfStock = cart.some(item => !item.inStock);

  return (
    <div>
      {hasOutOfStock && (
        <p style={{ color: "red" }}>
          ⚠️ Some items are out of stock!
        </p>
      )}
      <ul>
        {cart.map(item => (
          <li key={item.id}>
            {item.name} — {item.inStock ? "✅ In Stock" : "❌ Out of Stock"}
          </li>
        ))}
      </ul>
    </div>
  );
};
```

## `.every()`

> 🟣 **إيه هو؟** بيتحقق لو **كل العناصر** في الـ array شرطها `true` — بيرجع `true` أو `false`.

### Syntax

```js
array.every((element) => condition)
```

### مثال بسيط

```js
const ages = [20, 22, 25, 19];
const allAdults = ages.every(age => age >= 18);
console.log(allAdults); // true
```

### مثال واقعي

```js
const tasks = [
  { text: "Task 1", done: true },
  { text: "Task 2", done: true },
  { text: "Task 3", done: false },
];

const allDone = tasks.every(task => task.done);
// false — مفيش كل التاسكات خلصت
```

### ⚛️ في React — زرار Submit

```jsx
const FormPage = () => {
  const [fields, setFields] = useState([
    { id: 1, label: "Name", value: "" },
    { id: 2, label: "Email", value: "" },
    { id: 3, label: "Password", value: "" },
  ]);

  const allFilled = fields.every(field => field.value.trim() !== "");

  const handleChange = (id, value) => {
    setFields(fields.map(f => f.id === id ? { ...f, value } : f));
  };

  return (
    <div>
      {fields.map(field => (
        <input
          key={field.id}
          placeholder={field.label}
          value={field.value}
          onChange={(e) => handleChange(field.id, e.target.value)}
        />
      ))}
      <button disabled={!allFilled}>
        {allFilled ? "Submit ✅" : "Fill all fields first"}
      </button>
    </div>
  );
};
```

## `.reduce()`

> ⚫ **إيه هو؟** بيجمع كل عناصر الـ array في **قيمة واحدة** (مش array). الأقوى والأصعب — بيستخدم accumulator.

### Syntax

```js
array.reduce((accumulator, currentValue) => newAccumulator, initialValue)
```

### مثال بسيط — جمع أرقام

```js
const nums = [1, 2, 3, 4, 5];
const total = nums.reduce((sum, num) => sum + num, 0);
console.log(total); // 15
```

### مثال — إيجاد الأعلى

```js
const prices = [99, 299, 49, 199];
const max = prices.reduce((highest, price) => 
  price > highest ? price : highest, 0
);
console.log(max); // 299
```

### مثال — تحويل array لـ object

```js
const users = [
  { id: 1, name: "Ahmed" },
  { id: 2, name: "Sara" },
];

const usersById = users.reduce((acc, user) => {
  acc[user.id] = user;
  return acc;
}, {});

// { 1: { id: 1, name: "Ahmed" }, 2: { id: 2, name: "Sara" } }
```

### ⚛️ في React — حساب إجمالي السلة

```jsx
const CartSummary = () => {
  const [cart] = useState([
    { id: 1, name: "Laptop", price: 999, qty: 1 },
    { id: 2, name: "Mouse", price: 29, qty: 2 },
    { id: 3, name: "Keyboard", price: 79, qty: 1 },
  ]);

  const total = cart.reduce((sum, item) => sum + item.price * item.qty, 0);

  return (
    <div>
      <ul>
        {cart.map(item => (
          <li key={item.id}>
            {item.name} × {item.qty} = ${item.price * item.qty}
          </li>
        ))}
      </ul>
      <hr />
      <h3>Total: ${total}</h3>
    </div>
  );
};
```

## `.forEach()`

> 🔷 **إيه هو؟** بيمر على كل عنصر وينفذ function — **مش بيرجع array جديد**. بيستخدم للـ side effects زي الـ console.log أو الـ DOM manipulation.

### Syntax

```js
array.forEach((element, index) => { /* do something */ })
```

### مثال بسيط

```js
const fruits = ["apple", "banana", "mango"];
fruits.forEach((fruit, index) => {
  console.log(`${index + 1}. ${fruit}`);
});
// 1. apple
// 2. banana
// 3. mango
```

> [!info] ملحوظة في React بنستخدم `.map()` بدل `.forEach()` لأن map بترجع JSX. forEach مش بترجع حاجة فمش هتشتغل في الـ JSX مباشرة.

## `.includes()`

> 🔸 **إيه هو؟** بيتحقق لو **قيمة معينة موجودة** في الـ array — بيرجع `true` أو `false`.

### Syntax

```js
array.includes(value)
```

### مثال بسيط

```js
const colors = ["red", "green", "blue"];
console.log(colors.includes("green")); // true
console.log(colors.includes("yellow")); // false
```

### ⚛️ في React — Favorites System

```jsx
const ProductCard = ({ product }) => {
  const [favorites, setFavorites] = useState([1, 3]); // IDs المفضلة

  const isFav = favorites.includes(product.id);

  const toggleFav = () => {
    if (isFav) {
      setFavorites(favorites.filter(id => id !== product.id));
    } else {
      setFavorites([...favorites, product.id]);
    }
  };

  return (
    <div>
      <h3>{product.name}</h3>
      <button onClick={toggleFav}>
        {isFav ? "❤️ Remove from Favorites" : "🤍 Add to Favorites"}
      </button>
    </div>
  );
};
```

## `.flat()` و `.flatMap()`

> 🔹 **إيه هو؟** `.flat()` بيحول nested array لـ array عادي. `.flatMap()` بيعمل `.map()` وبعدين `.flat()` في خطوة واحدة.

### مثال `.flat()`

```js
const nested = [1, [2, 3], [4, [5, 6]]];
console.log(nested.flat());    // [1, 2, 3, 4, [5, 6]]
console.log(nested.flat(2));   // [1, 2, 3, 4, 5, 6]
console.log(nested.flat(Infinity)); // [1, 2, 3, 4, 5, 6]
```

### مثال `.flatMap()`

```js
const sentences = ["Hello World", "Learn React"];
const words = sentences.flatMap(s => s.split(" "));
console.log(words); // ["Hello", "World", "Learn", "React"]
```

### ⚛️ في React

```jsx
const TagsCloud = () => {
  const posts = [
    { id: 1, tags: ["react", "javascript"] },
    { id: 2, tags: ["css", "design"] },
    { id: 3, tags: ["react", "hooks"] },
  ];

  const allTags = [...new Set(posts.flatMap(post => post.tags))];
  // ["react", "javascript", "css", "design", "hooks"]

  return (
    <div>
      {allTags.map(tag => (
        <span key={tag} style={{ margin: "4px", padding: "4px 8px", background: "#eee" }}>
          #{tag}
        </span>
      ))}
    </div>
  );
};
```

## `.sort()`

> 🔶 **إيه هو؟** بيرتب عناصر الـ array. **بيعدل الـ array الأصلي** — لازم تعمل copy الأول.

### Syntax

```js
array.sort((a, b) => a - b)  // تصاعدي
array.sort((a, b) => b - a)  // تنازلي
```

### مثال أرقام

```js
const nums = [40, 1, 100, 5];
const asc = [...nums].sort((a, b) => a - b);
// [1, 5, 40, 100]

const desc = [...nums].sort((a, b) => b - a);
// [100, 40, 5, 1]
```

### مثال نصوص

```js
const names = ["Sara", "Ahmed", "Ali", "Mona"];
const sorted = [...names].sort();
// ["Ahmed", "Ali", "Mona", "Sara"]
```

### ⚛️ في React — ترتيب قابل للتغيير

```jsx
const ProductList = () => {
  const [sortOrder, setSortOrder] = useState("asc");
  const products = [
    { id: 1, name: "Laptop", price: 999 },
    { id: 2, name: "Phone", price: 499 },
    { id: 3, name: "Tablet", price: 299 },
  ];

  const sorted = [...products].sort((a, b) =>
    sortOrder === "asc" ? a.price - b.price : b.price - a.price
  );

  return (
    <div>
      <button onClick={() => setSortOrder(sortOrder === "asc" ? "desc" : "asc")}>
        Sort: {sortOrder === "asc" ? "⬆️ Low to High" : "⬇️ High to Low"}
      </button>
      <ul>
        {sorted.map(p => (
          <li key={p.id}>{p.name} — ${p.price}</li>
        ))}
      </ul>
    </div>
  );
};
```

## 🎯 مشروع React شامل

> Task Manager App يستخدم كل الـ methods اللي اتعلمناها

### 📁 Structure

```
src/
├── App.jsx           → State الرئيسي + منطق التطبيق
├── AddTask.jsx       → Form إضافة task جديد
├── TaskList.jsx      → عرض قائمة التاسكات
├── TaskItem.jsx      → كارت كل task
└── Summary.jsx       → ملخص باستخدام reduce + some + every
```

### `App.jsx`

```jsx
import { useState } from "react";
import AddTask from "./AddTask";
import TaskList from "./TaskList";
import Summary from "./Summary";

const App = () => {
  const [tasks, setTasks] = useState([
    { id: 1, text: "Learn React", done: false, priority: "high" },
    { id: 2, text: "Build project", done: false, priority: "medium" },
    { id: 3, text: "Deploy app", done: true, priority: "low" },
  ]);

  const [filter, setFilter] = useState("all"); // all | done | pending

  // .filter() — عرض حسب الفلتر
  const filteredTasks = tasks.filter(task => {
    if (filter === "done") return task.done;
    if (filter === "pending") return !task.done;
    return true;
  });

  // إضافة task — spread operator
  const addTask = (text) => {
    const newTask = { id: Date.now(), text, done: false, priority: "medium" };
    setTasks([...tasks, newTask]);
  };

  // حذف task — .filter()
  const deleteTask = (id) => {
    setTasks(tasks.filter(task => task.id !== id));
  };

  // Toggle done — .map() + findIndex
  const toggleTask = (id) => {
    setTasks(tasks.map(task =>
      task.id === id ? { ...task, done: !task.done } : task
    ));
  };

  return (
    <div style={{ maxWidth: "600px", margin: "0 auto", padding: "20px" }}>
      <h1>📝 Task Manager</h1>
      <AddTask onAdd={addTask} />
      <Summary tasks={tasks} />
      <div>
        {["all", "done", "pending"].map(f => (
          <button
            key={f}
            onClick={() => setFilter(f)}
            style={{ fontWeight: filter === f ? "bold" : "normal", margin: "4px" }}
          >
            {f}
          </button>
        ))}
      </div>
      <TaskList
        tasks={filteredTasks}
        onDelete={deleteTask}
        onToggle={toggleTask}
      />
    </div>
  );
};

export default App;
```

### `Summary.jsx`

```jsx
const Summary = ({ tasks }) => {
  // .reduce() — عدد المنجزة
  const doneCount = tasks.reduce((count, task) => 
    task.done ? count + 1 : count, 0
  );

  // .every() — كلهم خلصوا؟
  const allDone = tasks.every(task => task.done);

  // .some() — في واحدة high priority لسه؟
  const hasHighPriority = tasks.some(t => t.priority === "high" && !t.done);

  return (
    <div style={{ background: "#f9f9f9", padding: "12px", borderRadius: "8px", margin: "12px 0" }}>
      <p>📊 {doneCount} / {tasks.length} tasks completed</p>
      {allDone && <p>🎉 All tasks done!</p>}
      {hasHighPriority && <p>⚠️ You have high priority tasks pending!</p>}
    </div>
  );
};

export default Summary;
```

## 📊 ملخص سريع

|Method|بيرجع|الاستخدام|
|---|---|---|
|`.map()`|Array جديد|تحويل كل عنصر|
|`.filter()`|Array جديد|تصفية العناصر|
|`.find()`|عنصر واحد|إيجاد أول عنصر|
|`.findIndex()`|رقم index|إيجاد موقع عنصر|
|`.some()`|Boolean|عنصر واحد على الأقل يحقق الشرط|
|`.every()`|Boolean|كل العناصر تحقق الشرط|
|`.reduce()`|أي قيمة|تجميع العناصر في قيمة واحدة|
|`.forEach()`|undefined|side effects بس|
|`.includes()`|Boolean|هل القيمة موجودة؟|
|`.flat()`|Array|فرد الـ nested arrays|
|`.flatMap()`|Array|map + flat معاً|
|`.sort()`|نفس الـ Array|ترتيب العناصر|
