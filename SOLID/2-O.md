# تعريف OCP تاني بسرعة

> الكلاس يكون **مغلق للتعديل** لكن **مفتوح للإضافة**

يعني:

- ما نعدّلش الكود القديم
    
- نضيف كود جديد بدل ما نغيّر القديم
    

ليه؟ لأن الكود القديم غالباً شغال في production 💣

---

# مثال واقعي أقوى 💡

سيستم **حساب المرتبات**.

## Version 1 – فيه موظفين عاديين بس

```java
class SalaryCalculator {

    public double calculateSalary(String employeeType) {
        if(employeeType.equals("fulltime"))
            return 5000;
        return 0;
    }
}
```

---

## Version 2 – الشركة وظفت Intern 😅

نعدّل الكود:

```java
if(employeeType.equals("intern"))
    return 2000;
```

---

## Version 3 – الشركة جابت Freelancer 😭

نعدّل تاني:

```java
if(employeeType.equals("freelancer"))
    return 3000;
```

💣 المشكلة:  
كل موظف جديد = تعديل الكود القديم.

ده كسر OCP.

---

# الحل باستخدام Polymorphism ✅

بدل ما نسأل _نوع الموظف ايه؟_  
نخلي الموظف نفسه يحسب مرتبه.

---

## Step 1) Interface

```java
interface Employee {
    double calculateSalary();
}
```

---

## Step 2) كل نوع موظف كلاس مستقل

### FullTime

```java
class FullTimeEmployee implements Employee {
    public double calculateSalary() {
        return 5000;
    }
}
```

### Intern

```java
class InternEmployee implements Employee {
    public double calculateSalary() {
        return 2000;
    }
}
```

### Freelancer

```java
class FreelancerEmployee implements Employee {
    public double calculateSalary() {
        return 3000;
    }
}
```

---

## Step 3) SalaryCalculator ثابت لا يتغير

```java
class SalaryCalculator {
    public double calculate(Employee employee) {
        return employee.calculateSalary();
    }
}
```

لاحظ 💥  
الكلاس ده مش هيحتاج يتعدل تاني أبداً.

---

## الاستخدام

```java
public class Main {
    public static void main(String[] args) {

        SalaryCalculator calc = new SalaryCalculator();

        Employee emp1 = new FullTimeEmployee();
        Employee emp2 = new InternEmployee();

        System.out.println(calc.calculate(emp1));
        System.out.println(calc.calculate(emp2));
    }
}
```

# الكود كامل تحت بعضه 👇

## 1️⃣ Employee abstraction

```java
abstract class Employee {
    protected String name;

    public Employee(String name) {
        this.name = name;
    }

    public abstract double calculateSalary();
}
```

لاحظ:

- هنا حطينا الـ behavior المشترك
    
- وكل نوع موظف هيحسب مرتبه بطريقته
    

---

## 2️⃣ FullTimeEmployee

```java
class FullTimeEmployee extends Employee {

    public FullTimeEmployee(String name) {
        super(name);
    }

    @Override
    public double calculateSalary() {
        return 5000;
    }
}
```

---

## 3️⃣ InternEmployee

```java
class InternEmployee extends Employee {

    public InternEmployee(String name) {
        super(name);
    }

    @Override
    public double calculateSalary() {
        return 2000;
    }
}
```

---

## 4️⃣ FreelancerEmployee

```java
class FreelancerEmployee extends Employee {

    public FreelancerEmployee(String name) {
        super(name);
    }

    @Override
    public double calculateSalary() {
        return 3000;
    }
}
```

---

## 5️⃣ PayrollService (بقى بسيط جداً)

```java
class PayrollService {

    public void printSalary(Employee employee) {
        double salary = employee.calculateSalary();
        System.out.println(employee.name + " salary = " + salary);
    }
}
```

لاحظ 💥  
مفيش:

- if
    
- switch
    
- instanceof
    

الكلاس ده **مش هيتعدل طول عمره**.

---

## 6️⃣ Main

```java
public class Main {
    public static void main(String[] args) {

        PayrollService payroll = new PayrollService();

        Employee emp1 = new FullTimeEmployee("Ali");
        Employee emp2 = new InternEmployee("Sara");
        Employee emp3 = new FreelancerEmployee("Omar");
        Employee emp4 = new InternEmployee("Sara");

        payroll.printSalary(emp1);
        payroll.printSalary(emp2);
        payroll.printSalary(emp3);
    }
}
```

# 🔥 دلوقتي شوف OCP اتحقق ازاي

الشركة وظفت RemoteEmployee 😎  
نضيف كلاس جديد فقط:

```java
class RemoteEmployee extends Employee {

    public RemoteEmployee(String name) {
        super(name);
    }

    @Override
    public double calculateSalary() {
        return 4000;
    }
}
```

هل عدلنا PayrollService؟  
❌ لا  
هل عدلنا Employee؟  
❌ لا

بس ضفنا Class جديد 🎉
