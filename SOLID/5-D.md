## D — Dependency Inversion Principle

**اعتمد على Interface وليس Class مباشر.**

❌

```
class UserService {   EmailService emailService =      new EmailService();}
```

UserService مربوط بـ EmailService مباشرة.

 زي ال controller depends on service not serviceimpl  عشان لو غيرنا في ال  implementation   هنضطر نغير في ال controller
