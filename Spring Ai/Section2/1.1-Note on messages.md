أولًا، الكود اللي كتبته فيه مشكلة بسيطة. أنت نسيت تبعت **رسالة المستخدم**.

المفروض يبقى كده:

```java
@GetMapping("/chat")
public String chat(@RequestParam("message") String message) {

    return chatClient
            .prompt()
            .system("""
                    You are a senior Java Spring Boot developer.
                    You will be given a message from the user, and you will
                    respond with a helpful answer in the context of Java Spring Boot development.
                    """)
            .user(message)
            .call()
            .content();
}
```

لاحظ السطر ده:

```java
.user(message)
```

بدونه، الـ LLM مش هيعرف المستخدم سأل إيه أصلاً.

---

## طيب لو المستخدم سأل:

```text
What is the best chest workout?
```

والـ System Message بتقول:

```text
You are a senior Java Spring Boot developer.
Only answer questions related to Java Spring Boot.
```

### غالبًا هيحصل إيه؟

الـ LLM هيرد بحاجة زي:

> I'm here to help with Java Spring Boot questions. Please ask a question related to Spring Boot.

لأن الـ System Message وجهته إنه يركز على Spring Boot فقط.

---

## لكن خد بالك من حاجة مهمة جدًا

الـ **System Message مش قانون**، هو **تعليمات ذات أولوية عالية**.

يعني لو كتبت:

```text
You are a Java developer.
```

بس ما قلتش:

```text
Never answer questions outside Java.
```

فبعض الموديلات ممكن ترد على سؤال الجيم برضه، لأنها شايفة إن مفيش منع صريح.

---

## لو عايزه يرفض أي سؤال خارج Java

اكتب الـ System Message بالشكل ده:

```text
You are a senior Java Spring Boot developer.

Only answer questions related to Java and Spring Boot.

If the user asks anything unrelated to Java or Spring Boot,
politely refuse and ask them to ask a Java-related question instead.
```

الآن لو المستخدم قال:

```text
How can I build bigger biceps?
```

هيكون الرد غالبًا:

> Sorry, I can only answer questions related to Java and Spring Boot. Please ask a Java-related question.

---

### ملخص سريع

- ✅ `System Message` = تعليمات للموديل.
    
- ✅ الموديل يحاول يلتزم بيها لأنها أعلى أولوية.
    
- ✅ لو التعليمات كانت عامة، ممكن يجاوب على أسئلة خارج الموضوع.
    
- ✅ لو عايزه يرفض، اكتب ذلك **بشكل صريح** داخل الـ System Message.
