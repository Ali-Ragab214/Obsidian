## **1️⃣ What is Spring Boot**

- **Spring Boot** = Framework مبني على **Spring** لتسهيل بناء تطبيقات Java بسرعة.
    
- يقلل الحاجة لكتابة **configuration كثيرة**.
    
- يأتي مع **Embedded Server** (Tomcat مدمج).
    
- يدعم **REST APIs** و **Microservices** بسهولة.
    
- يوفر **Production-ready features**: logging، monitoring، metrics.
    
- يشتغل مع **Clean Architecture و Spring Core concepts**.
    

---

## **2️⃣ Auto Configuration**

- **ميزة أساسية في Spring Boot**: التطبيق يجهز نفسه تلقائيًا حسب **المكتبات (dependencies)** الموجودة.
    
- Annotation رئيسي: `@SpringBootApplication` → يشغل Auto Configuration.
    
- أمثلة:
    
    - `spring-boot-starter-web` → يجهز Spring MVC + Tomcat + JSON converter
        
    - `spring-boot-starter-data-jpa` → يجهز Hibernate + DataSource + JPA
        
- الهدف: **توفير الوقت وتقليل الـ configuration اليدوي**.
    

---

## **3️⃣ Convention over Configuration**

- يعني Spring Boot **يفترض إعدادات افتراضية (defaults)** لتقليل الكتابة اليدوية.
    
- أمثلة:
    
    - `application.properties` يجب أن يكون في `src/main/resources`
        
    - Main Class + sub-packages → Spring Boot سيجدهم تلقائيًا
        
    - `@RestController` → يتحول تلقائيًا لـ JSON
        
    - Default port = 8080
        
- مرتبط بـ **Auto Configuration**: القواعد الافتراضية تُطبق تلقائيًا.
    

---

## **4️⃣ Starter Dependencies**

- **Dependencies جاهزة** تحتوي على مكتبات مرتبطة ببعض لتسهيل الإعداد.
    
- هدفها: **تسهيل setup المشروع بدون إضافة كل مكتبة يدويًا**.
    
- أمثلة:
    
    - `spring-boot-starter-web` → Spring MVC + Tomcat + Jackson
        
    - `spring-boot-starter-data-jpa` → Hibernate + JPA + DataSource
        
    - `spring-boot-starter-security` → Spring Security
        
    - `spring-boot-starter-test` → JUnit + Mockito
        
- Starter Dependencies هي اللي **تشغل Auto Configuration تلقائيًا**.

## **💡 Mind Map ربط الـ 4 توبيكات**

```
               Spring Boot
                     |
        --------------------------------
        |              |               |
   Auto Configuration   Convention    Starter Dependencies
        |               over Config          |
  يعتمد على المكتبات      يقلل الكتابة        مجموعة مكتبات جاهزة
        |                  اليدوية               |
  spring-boot-starter-*   default setups       يشغل Auto Config
        |
  web, data-jpa, security...
```

**شرح بصري سريع:**

- **Spring Boot** هو الأساس.
    
- **Auto Configuration** يعتمد على المكتبات اللي ضفتها.
    
- **Convention over Configuration** يعطيك defaults لتقليل العمل اليدوي.
    
- **Starter Dependencies** هي المكتبات الجاهزة اللي تحرك Auto Configuration تلقائيًا.
