# Pagination — الدليل الشامل

---

## ما هي الـ Pagination؟

تخيل عندك **مليون product** في الـ database وعايز تجيبهم كلهم في request واحدة.

```
❌ بدون Pagination:
SELECT * FROM products;
→ مليون record في الـ memory
→ الـ server بيموت
→ الـ client بيستنى دهر

✅ مع Pagination:
SELECT * FROM products LIMIT 10 OFFSET 0;
→ 10 records بس
→ سريع وخفيف
→ الـ client يطلب الصفحة اللي يريدها
```

---

## المصطلحات بالتفصيل

---

### `limit`

كام record تجيب في كل مرة.

```sql
SELECT * FROM products LIMIT 10;
-- جيب 10 بس
```

---

### `offset`

ابدأ من الـ record رقم كام.

```sql
SELECT * FROM products LIMIT 10 OFFSET 0;  -- الصفحة 1
SELECT * FROM products LIMIT 10 OFFSET 10; -- الصفحة 2
SELECT * FROM products LIMIT 10 OFFSET 20; -- الصفحة 3
```

```
العلاقة:
offset = page * size
offset = 0 * 10 = 0   → الصفحة الأولى
offset = 1 * 10 = 10  → الصفحة التانية
offset = 2 * 10 = 20  → الصفحة التالتة
```

---

### `page`

رقم الصفحة — بيبدأ من **0** في Spring.

```
page=0 → الصفحة الأولى
page=1 → الصفحة التانية
page=2 → الصفحة التالتة
```

---

### `size`

عدد العناصر في كل صفحة.

```
size=10 → 10 عناصر في كل صفحة
size=20 → 20 عناصر في كل صفحة
```

---
PageRequest implements Pageable 
### `Pageable`

ده الـ interface اللي بيتبعت للـ repository، `PageRequest` بيـ implement منه.

```java
Pageable pageable = PageRequest.of(0, 10);
// ممكن تبعته للـ repository مباشرة
```

---
### `PageRequest`

ده الـ object اللي Spring بيستخدمه عشان يبني الـ pagination query.

```java
PageRequest.of(page, size)
// page=0, size=10 → LIMIT 10 OFFSET 0

PageRequest.of(page, size, Sort.by("createdAt").descending())
// نفس الكلام + ترتيب بالتاريخ
```

---

### `Page<T>`

ده الـ object اللي Spring بيرجعه من الـ repository، جوّاه:

```java
page.getContent()        // List<T> — الـ data نفسها
page.getTotalElements()  // إجمالي عدد العناصر في الـ database
page.getTotalPages()     // إجمالي عدد الصفحات
page.getNumber()         // رقم الصفحة الحالية
page.getSize()           // حجم الصفحة
page.isFirst()           // هل دي أول صفحة؟
page.isLast()            // هل دي آخر صفحة؟
page.hasNext()           // في صفحة بعدها؟
page.hasPrevious()       // في صفحة قبلها؟
```

---

### `Pageable`

ده الـ interface اللي بيتبعت للـ repository، `PageRequest` بيـ implement منه.

```java
Pageable pageable = PageRequest.of(0, 10);
// ممكن تبعته للـ repository مباشرة
```

## المثال العملي الكامل

### Entity

```java
@Entity
@Table(name = "courses")
public class Course extends BaseEntity {
    private String title;
    private String description;
    private BigDecimal price;
    private CourseStatus status;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "instructor_id")
    private User instructor;
}
```

---

### Custom Pagination Response

**هل نعمل response مخصص؟ أيوه ✅**

لأن الـ `Page<T>` بتاع Spring فيه معلومات كتير مش محتاجها الـ client، وشكله مش نظيف.

**هل يكون `class` أو `record`؟**

```java
// ✅ record — لأن الـ Pagination response مش بيتغير
public record PageResponse<T>(
    List<T> content,
    int pageNumber,
    int pageSize,
    long totalElements,
    int totalPages,
    boolean isFirst,
    boolean isLast,
    boolean hasNext,
    boolean hasPrevious
) {
    // Static factory method عشان نبني منه بسهولة
    public static <T> PageResponse<T> of(Page<T> page) {
        return new PageResponse<>(
            page.getContent(),
            page.getNumber(),
            page.getSize(),
            page.getTotalElements(),
            page.getTotalPages(),
            page.isFirst(),
            page.isLast(),
            page.hasNext(),
            page.hasPrevious()
        );
    }
}
```

### Repository

```java
public interface CourseRepository extends JpaRepository<Course, Long> {

    // Pagination بسيطة
    Page<Course> findByStatus(CourseStatus status, Pageable pageable);

    // مع search
    Page<Course> findByStatusAndTitleContainingIgnoreCase(
        CourseStatus status,
        String title,
        Pageable pageable
    );

    // بتاعت instructor معين
    Page<Course> findByInstructorEmail(String email, Pageable pageable);

    // Custom query
    @Query("SELECT c FROM Course c WHERE c.status = :status AND c.price <= :maxPrice")
    Page<Course> findByStatusAndMaxPrice(
        @Param("status") CourseStatus status,
        @Param("maxPrice") BigDecimal maxPrice,
        Pageable pageable
    );
}
```

### Service Interface

```java
public interface CourseService {
    ResponseEntity<ApiResponse<PageResponse<CourseResponse>>> getAllPublishedCourses(
        int page,
        int size,
        String sortBy,
        String search
    );
}
```

---

### ServiceImpl

```java
@Service
@RequiredArgsConstructor
public class CourseServiceImpl implements CourseService {

    private final CourseRepository courseRepository;
    private final CourseMapper courseMapper;

    @Override
    public ResponseEntity<ApiResponse<PageResponse<CourseResponse>>> getAllPublishedCourses(
            int page,
            int size,
            String sortBy,
            String search) {

        // 1️⃣ بناء الـ Pageable
        Pageable pageable = PageRequest.of(
            page,
            size,
            Sort.by(sortBy).descending()
        );

        // 2️⃣ جيب الـ data من الـ repository
        Page<Course> coursePage;

        if (search != null && !search.isBlank()) {
            coursePage = courseRepository
                .findByStatusAndTitleContainingIgnoreCase(
                    CourseStatus.PUBLISHED,
                    search,
                    pageable
                );
        } else {
            coursePage = courseRepository
                .findByStatus(CourseStatus.PUBLISHED, pageable);
        }

        // 3️⃣ حوّل من Entity لـ DTO
        Page<CourseResponse> responseMap = coursePage
            .map(courseMapper::toResponse);

        // 4️⃣ ابني الـ PageResponse
        PageResponse<CourseResponse> pageResponse = PageResponse.of(responseMap);

        // 5️⃣ رجّع الـ ApiResponse
        return ResponseEntity.ok(
            ApiResponse.success(pageResponse, "Courses retrieved successfully")
        );
    }
}
```

---

### Controller

```java
@RestController
@RequestMapping("/api/courses")
@RequiredArgsConstructor
public class CourseController {

    private final CourseService courseService;

    @GetMapping
    public ResponseEntity<ApiResponse<PageResponse<CourseResponse>>> getAllCourses(
            @RequestParam(defaultValue = "0") int page,
            @RequestParam(defaultValue = "10") int size,
            @RequestParam(defaultValue = "createdAt") String sortBy,
            @RequestParam(required = false) String search) {

        return courseService.getAllPublishedCourses(page, size, sortBy, search);
    }
}
```

## الفلو كامل

```
Client
  │
  │  GET /api/courses?page=0&size=10
  ↓
Controller
  │  يستقبل الـ params
  │  يبعتهم للـ Service
  ↓
ServiceImpl
  │  يبني PageRequest.of(0, 10)
  │  يبعته للـ Repository
  ↓
Repository
  │  يعمل:
  │  SELECT * FROM courses
  │  WHERE status = 'PUBLISHED'
  │  LIMIT 10 OFFSET 0
  │  يرجع Page<Course>
  ↓
ServiceImpl
  │  يعمل .map(courseMapper::toResponse)
  │  يبني PageResponse.of(page)
  │  يحطه في ApiResponse
  ↓
Controller
  │  يرجعه كـ ResponseEntity
  ↓
Client
  └── JSON Response ✅
```

## ملخص القرارات

```
✅ PageResponse → record  (immutable + نظيف)
✅ مش بترجع Page<T> مباشرة  (كتير ومش منظم)
✅ الـ default page=0, size=10
✅ دايماً حط validation على الـ size
   عشان حد ميبعتش size=999999
✅ الـ sort دايماً على createdAt أو updatedAt
```
