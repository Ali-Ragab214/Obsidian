## 🧠 يعني إيه Separation of Concerns (SoC)؟

**Separation of Concerns** معناها:

> تقسيم التطبيق إلى أجزاء صغيرة، كل جزء مسؤول عن “مهمة واحدة فقط”، بدل ما كل الكود يبقى في مكان واحد وبيعمل كل حاجة.

الفكرة الأساسية:  
👉 كل طبقة/كلاس “تركّز على حاجة واحدة فقط”

---

## 🎯 مثال بسيط من حياتك

تخيل مطعم:

- 👨‍🍳 الشيف → يطبخ الأكل
    
- 🧾 الكاشير → يستقبل الفلوس
    
- 🚚 الدليفري → يوصل الطلب
    

❌ لو نفس الشخص بيعمل كل ده → فوضى  
✔️ لما كل واحد له دور → نظام شغال صح

---

# 💻 إزاي طبقنا SoC في مشروعك؟

خلينا نربطها بكود الـ Image system عندك 👇

---

## 1. 🧩 Controller (مسؤول عن الـ HTTP فقط)

```java
ImageController
```

✔️ دوره:

- يستقبل request
    
- يرجع response
    
- ما يعملش business logic
    

❌ مش مسؤول عن:

- تخزين الصورة
    
- التعامل مع DB
    

👉 يعني مجرد “بوابة دخول API”

---

## 2. 🧠 Service (Business Logic)

```java
ImageService
```

✔️ دوره:

- يرفع الصور
    
- يحول MultipartFile إلى Blob
    
- يربط الصورة بالـ Product
    
- يتعامل مع rules
    

❌ مش مسؤول عن:

- HTTP
    
- ResponseEntity
    

👉 ده “العقل بتاع النظام”

---

## 3. 🗄️ Repository (Data Access)

```java
ImageRepository
```

✔️ دوره:

- CRUD على DB
    
- save / find / delete
    

❌ مش مسؤول عن:

- business logic
    
- validation
    
- HTTP
    

👉 ده “بوابة الداتا بيز فقط”

---

## 4. 📦 DTO (Data Shape للـ API)

```java
ImageDto
```

✔️ دوره:

- تحديد شكل البيانات اللي بتطلع للـ client
    
- منع كشف الـ Entity مباشرة
    

👉 ده “شكل الداتا الخارجي”

---

## 5. 🧱 Entity (Database Model)

```java
Image
```

✔️ دوره:

- تمثيل الجدول في DB
    
- mapping relations
    

👉 ده “شكل الداتا الداخلي”

---

# 🔥 النتيجة: إحنا طبقنا SoC إزاي؟

|Layer|مسؤول عن|
|---|---|
|Controller|HTTP Requests/Responses|
|Service|Business Logic|
|Repository|Database Access|
|DTO|Response Shape|
|Entity|Database Structure|

---

# 🚀 ليه ده مهم جدًا؟

لو ما طبقتش SoC:

❌ كودك يبقى في Controller كله  
❌ صعب تعدل أو تختبر  
❌ أي تغيير يكسر النظام  
❌ تكرار كود بشكل كبير

---

# 🧠 مثال خطأ (بدون SoC)

```java
@PostMapping("/upload")
public Image upload(...) {
    // save file
    // business logic
    // database call
    // response formatting
}
```

👆 ده كده “مطبوخ في طبق واحد” 😄

---

# ✔️ مثال صح (مع SoC)

Controller:

```java
imageService.saveImage(...)
```

Service:

```java
// logic here
```

Repository:

```java
imageRepository.save(...)
```
