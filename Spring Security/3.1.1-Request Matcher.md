الـ **Request Matcher** في Spring Security هو طريقة نقول بيها للنظام:

> “الـ rules دي تتطبق على أي Request ؟”

يعني هو المسؤول عن **تحديد أي URL أو Request هتتطبق عليه قواعد الأمان**.

---

## الفكرة ببساطة

Spring Security بيحتاج يعرف:

- مين محتاج login؟
    
- مين admin بس؟
    
- مين متاح للجميع؟
    

عشان كده بنستخدم **requestMatchers()**.

---

## مثال سريع

تخيل عندك APIs:

- `/api/public/**` → متاح لأي حد
    
- `/api/users/**` → لازم login
    
- `/api/admin/**` → لازم Admin
    

بنكتب كده:

```java
@Bean
public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
    http
        .authorizeHttpRequests(auth -> auth
            .requestMatchers("/api/public/**").permitAll()
            .requestMatchers("/api/users/**").authenticated()
            .requestMatchers("/api/admin/**").hasRole("ADMIN")
            .anyRequest().denyAll()
        );

    return http.build();
}
```

---

## يعني ايه Request Matcher هنا؟

السطر ده:

```java
.requestMatchers("/api/admin/**")
```

ده اسمه **Request Matcher**  
يعني: “لو أي Request جاي على المسار ده → طبق عليه rule معينة”.

---

## نقدر نعمل Match على ايه؟

### 1️⃣ حسب الـ URL

```java
.requestMatchers("/login")
.requestMatchers("/api/**")
.requestMatchers("/products/*")
```

الرموز:

- `*` = جزء واحد
    
- `**` = أي عدد من الأجزاء
    

مثال:

- `/api/*` → `/api/users` ✔️
    
- `/api/**` → `/api/users/1/orders` ✔️
    

---

### 2️⃣ حسب نوع الـ HTTP Method

```java
.requestMatchers(HttpMethod.GET, "/products/**").permitAll()
.requestMatchers(HttpMethod.POST, "/products/**").hasRole("ADMIN")
```

يعني:

- GET المنتجات → أي حد
    
- POST إضافة منتج → Admin فقط
    

ودي نقطة مهمة جدًا 🔥

---

### 3️⃣ حسب أكتر من مسار

```java
.requestMatchers("/login", "/register", "/swagger/**").permitAll()
```

---

## ليه Request Matcher مهم؟

بدونه Spring Security هيقفل كل حاجة 😄

هو اللي بيحدد:

- public endpoints
    
- protected endpoints
    
- admin endpoints
    

---

## الخلاصة السريعة

Request Matcher =  
أداة في Spring Security لتحديد **أي Requests هتتطبق عليها قواعد الحماية**.

---
