# 🧠 Mind Map - `requestMatchers()` in Spring Security

```
requestMatchers()│├── Permit Access│   └── permitAll()│├── Authentication│   ├── authenticated()│   └── anonymous()│├── Authorization│   ├── hasRole("ADMIN")│   ├── hasRole("USER")│   ├── hasAnyRole(...)│   ├── hasAuthority(...)│   └── hasAnyAuthority(...)│├── Path Matching│   ├── "/api/*"│   │    └── One Path Segment│   ││   └── "/api/**"│        └── Any Number of Segments│├── HTTP Methods│   ├── GET│   ├── POST│   ├── PUT│   ├── DELETE│   └── PATCH│└── Order Matters    ├── Specific Rules First    └── General Rules Last
```

---

# 📌 أشهر الصيغ

### السماح للجميع

```
.requestMatchers("/auth/**").permitAll()
```

---

### لازم يكون عامل Login

```
.requestMatchers("/profile/**").authenticated()
```

---

### Admin فقط

```
.requestMatchers("/admin/**").hasRole("ADMIN")
```

---

### User أو Admin

```
.requestMatchers("/dashboard/**").hasAnyRole("USER", "ADMIN")
```

---

### حسب الـ HTTP Method

```
.requestMatchers(HttpMethod.GET, "/products/**").permitAll().requestMatchers(HttpMethod.POST, "/products/**").hasRole("ADMIN")
```

---

# ⭐ Wildcards

### `*`

```
"/api/*"
```

يطابق:

```
/api/users/api/admin
```

لا يطابق:

```
/api/admin/users
```

---

### `**`

```
"/api/**"
```

يطابق:

```
/api/users/api/admin/api/admin/users/api/admin/users/1
```

---

# ⚠️ أهم فخ في Spring Security

❌ خطأ

```
.requestMatchers("/api/**").permitAll().requestMatchers("/api/admin/**").hasRole("ADMIN")
```

لأن أول Rule ستلتقط كل شيء.

---

✅ صح

```
.requestMatchers("/api/admin/**").hasRole("ADMIN").requestMatchers("/api/**").permitAll()
```

---

# 🔐 401 vs 403

### 401 Unauthorized

```
Not Authenticated
```

المستخدم لم يسجل الدخول.

---

### 403 Forbidden

```
AuthenticatedBut Not Authorized
```

المستخدم سجل الدخول لكن ليس لديه الصلاحية.

---

# 🚀 Template هتستخدمه في 90% من المشاريع

```
http.authorizeHttpRequests(auth -> auth    .requestMatchers("/api/v1/auth/**")    .permitAll()    .requestMatchers("/api/v1/admin/**")    .hasRole("ADMIN")    .requestMatchers(HttpMethod.GET, "/api/v1/products/**")    .permitAll()    .anyRequest()    .authenticated());
```

احفظ القاعدة الذهبية دي:

> **Spring Security يقرأ `requestMatchers()` من أعلى لأسفل، وأول Match هو الذي يتم تطبيقه.** 🎯
