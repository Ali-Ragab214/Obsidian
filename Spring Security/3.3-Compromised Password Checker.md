---

## أولاً يعني ايه Compromised Password أصلاً؟

زي ما قولنا قبل كده:  
هو باسورد موجود في **تسريبات عالمية** (Data Breaches).

مواقع كتير اتاخترقت واتسرب منها ملايين الباسوردات.  
أشهر موقع بيجمع التسريبات دي هو موقع اسمه  
**Have I Been Pwned**.

---

## ثانياً الكود بتاعك بيعمل ايه؟

```java
@Bean
public CompromisedPasswordChecker compromisedPasswordChecker() {
    return new HaveIBeenPwnedRestApiPasswordChecker();
}
```

إنت كدا بتقول لـ Spring Security:

> قبل ما أقبل أي باسورد جديد من المستخدم  
> روح اسأل موقع HaveIBeenPwned هل الباسورد ده متسرب قبل كده ولا لأ.

لو متسرب → يرفض التسجيل.

---

## ايه هو HaveIBeenPwned ؟

هو موقع عالمي بيحتفظ بقاعدة بيانات فيها **مليارات الباسوردات المسروقة**.

Spring Security عمل integration جاهزة معاه 🔥  
يعني Spring هو اللي بيكلم الـ API مش إنت.

---

## بيحصل ايه وقت تسجيل مستخدم جديد؟

لما user يعمل register:

1️⃣ المستخدم يكتب password  
2️⃣ Spring يعمل hash للباسورد  
3️⃣ يبعت hash للـ API بتاع HaveIBeenPwned  
4️⃣ لو الباسورد موجود في التسريبات  
❌ يرفض التسجيل  
5️⃣ لو مش موجود  
✅ يكمل التسجيل عادي

المستخدم مش بيحس بأي حاجة.

---

## ليه ده مهم جداً؟

لأن أغلب المستخدمين بيستخدموا باسوردات ضعيفة جداً زي:

- 123456
    
- password
    
- qwerty
    
- 123456789
    

ودي كلها موجودة في التسريبات.

فإنت بتحمي المستخدم **حتى لو هو مش فاهم أمان**.

---

## هل ده شائع حالياً؟

أيوه وبقوة 🔥

ده مستخدم في:

- GitHub
    
- Microsoft
    
- Google
    
- Cloudflare
    
- شركات fintech و banking
    

وده بقى يعتبر **Best Practice** في Security الحديثة.

اسمه:  
👉 Breached Password Protection

وده بقى requirement في معايير أمان كتير زي:

- OWASP
    
- NIST

## خلاصة بسيطة تحفظها ❤️

|الحاجة|معناها|
|---|---|
|CompromisedPasswordChecker|يفحص الباسورد متسرب ولا لأ|
|HaveIBeenPwnedRestApiPasswordChecker|يكلم API عالمي للباسوردات المسروقة|
|بيشتغل امتى|وقت Register أو تغيير الباسورد|
|فايدته|يمنع المستخدم يستخدم باسورد متسرب|
|هل حديث وشائع|جداً و Best Practice|
