``
```java
@Override  
    public String generateToken(Map<String, Object> extraClaims, UserDetails userDetails) {  
        return Jwts.builder()  
                .setClaims(extraClaims) //like roles and permissions or any other information we want to include in the token  
                .setSubject(userDetails.getUsername())//the owner of the token  
                .setIssuedAt(new Date((System.currentTimeMillis())))//the time when the token was issued  
                .setExpiration(new Date(System.currentTimeMillis() + JWT_EXPIRATION))  
                .signWith(getSigningKey(), Jwts.SIG.HS256)//this is the algorithm we will use to sign the token and the key we will use to sign it  
                .compact();//this will generate the token and return it as a string  
    }  
  
    private SecretKey getSigningKey() {  
byte[] keyBytes = Decoders.BASE64.decode(SECRET_KEY);  
return Keys.hmacShaKeyFor(keyBytes);  
    }
```

# الشكل الحقيقي للفانكشن

خلينا نكتبها ونشرح كل سطر 👇

```java
public String generateToken(Map<String, Object> extraClaims, UserDetails userDetails) {
    return Jwts.builder()
            .setClaims(extraClaims)                     // 1️⃣ البيانات الإضافية
            .setSubject(userDetails.getUsername())     // 2️⃣ صاحب التوكن
            .setIssuedAt(new Date(System.currentTimeMillis())) // 3️⃣ وقت الإنشاء
            .setExpiration(new Date(System.currentTimeMillis() + 1000 * 60 * 60 * 24)) // 4️⃣ انتهاء بعد 24 ساعة
            .signWith(getSigningKey(), SignatureAlgorithm.HS256) // 5️⃣ التوقيع
            .compact();
}
```

# السطر الأول

```java
byte[] keyBytes = Decoders.BASE64.decode(SECRET_KEY);
```

## يعني ايه Base64؟

احنا عادة بنحط الـ secret في application.properties كـ string:

```properties
jwt.secret=Y29vbC1zZWNyZXQta2V5LTEyMw==
```

ده مش النص الحقيقي…  
ده **Base64 encoded string**.

### ليه بنعمل Encode أصلاً؟

لأسباب أمنية:

- نخلي المفتاح شكله random
    
- نقدر نخزنه في env variables بسهولة
    
- نتأكد إنه طويل وقوي
    

---

## يحصل ايه هنا؟

السطر ده:

```java
Decoders.BASE64.decode(SECRET_KEY);
```

بيحوّل:

```
Y29vbC1zZWNyZXQta2V5LTEyMw==
```

إلى:

```
cool-secret-key-123
```

لكن مش String…  
بيحوّلها إلى **byte[]**

ليه bytes؟  
لأن التشفير بيتعامل بالـ bytes مش النصوص.

---

# السطر الثاني (الأهم 🔥)

```java
return Keys.hmacShaKeyFor(keyBytes);
```

هنا بيحصل السحر ✨

بنحوّل الـ bytes إلى:

```java
SecretKey
```

يعني مفتاح تشفير رسمي من Java Crypto.

النوع ده اسمه:

```
javax.crypto.SecretKey
```

وده النوع اللي خوارزمية **HS256** تفهمه.

---

## ليه مش نستخدم الـ bytes مباشرة؟

علشان مكتبة JWT محتاجة **Key object** يطابق مواصفات خوارزمية HMAC.

الميثود دي:

```java
Keys.hmacShaKeyFor()
```

بتتأكد إن:

- طول المفتاح مناسب
    
- صالح لخوارزمية HS256
    
- آمن للاستخدام
    

لو المفتاح قصير → يرمي Exception 🔥

وده مهم جداً للأمان.
