```java 
@Override  
public String extractUsername(String token) {  
    return extractClaim(token, Claims::getSubject);  
}  
  
private<T> T extractClaim(String token , Function<Claims,T>  claimsResolver)  
{  
    final Claims claims = extractAllClaims(token);  
    return claimsResolver.apply(claims);  
}  
  
private Claims extractAllClaims(String token)  
{  
    return Jwts.parser()  
            .verifyWith(getSigningKey())  
            .build()  
            .parseSignedClaims(token)  
            .getPayload();  
}
```


شوفهم من تحت لفوق 


الكود ده مسؤوليته:

- يفك التوكن
    
- يتأكد إنه متوقّع صح
    
- يقرأ الـ claims اللي جواه
    
- يطلع أي معلومة منه (زي username)
    

خلينا نمشي خطوة خطوة 👇

# ندخل على أهم جزء 👇

# 🔥 Generic Method

```java
private <T> T extractClaim(String token , Function<Claims,T> claimsResolver)
```

ركز معايا هنا لأن ده مفهوم مهم جداً في Java.

## يعني ايه `<T>` ؟

ده اسمه **Generic Type**.

معناه:

> الفانكشن تقدر ترجع أي نوع بيانات.

مش محددين ترجع:

- String
    
- Date
    
- Boolean
    

لا… ممكن ترجع أي حاجة.

يعني الفانكشن shape بتاعها:

```java
ترجع أي نوع T
```

---

## الباراميتر الغريب 👀

```java
Function<Claims,T> claimsResolver
```

ده معناه:

> هنمرر "فانكشن" جوه فانكشن 😎

يعني الفانكشن دي بتستقبل:

- التوكن
    
- وفانكشن تقولها "هاتلي انهي claim؟"
    

---

## نشوف التنفيذ

```java
final Claims claims = extractAllClaims(token);
return claimsResolver.apply(claims);
```

الخطوات:

1️⃣ نفك التوكن ونجيب كل الـ claims  
2️⃣ نشغّل الفانكشن اللي المستخدم بعتها  
3️⃣ نرجع النتيجة

# طيب يعني ايه Claims::getSubject ؟

دي اسمها **Method Reference**

يعني بنقول للفانكشن:

> لما تجيب claims… نفّذ getSubject()

يعني عملياً ده نفس الكلام:

```java
claims -> claims.getSubject()
```

# نروح للميثود الأخيرة 👇

## extractAllClaims()

```java
private Claims extractAllClaims(String token)
{
    return Jwts.parser()
            .verifyWith(getSigningKey())
            .build()
            .parseSignedClaims(token)
            .getPayload();
}
```

دي بتعمل 3 حاجات مهمين جداً:

### 1️⃣ تفك التوكن

```java
Jwts.parser()
```

### 2️⃣ تتأكد إن التوقيع صحيح 🔐

```java
.verifyWith(getSigningKey())
```

لو التوكن متزوّر → Exception فوراً 💥

### 3️⃣ تطلع الـ payload (البيانات)

```java
.parseSignedClaims(token)
.getPayload();
```

وده اللي اسمه:

```java
Claims
```

اللي فيه:

- subject
    
- expiration
    
- issuedAt
    
- extraClaims

# الخلاصة النهائية

## extractAllClaims()

تفك التوكن + تتحقق من التوقيع + ترجع البيانات.

## extractClaim() (Generic)

آلة مرنة تطلع أي claim من التوكن.

## extractUsername()

استخدام جاهز للـ generic method عشان يطلع username.
