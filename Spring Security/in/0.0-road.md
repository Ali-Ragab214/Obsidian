# رأيي

**دي تستحق كورس كامل، مش مجرد ريكاب.**

وأعتقد من اللي شوفته في أسئلتك الفترة اللي فاتت، إنك هتستفيد جدًا لو عملناها **بمستوى الشركات**، مش مجرد شرح ينجحك في الكورس.

يعني نشرح:

- كيف Spring Security يعمل داخليًا (Internals).
    
- لماذا كل Component موجود.
    
- كيف يربط مع JWT.
    
- ثم بعد ذلك ننتقل إلى OAuth2 وKeycloak، وساعتها هتفهمهم بسهولة لأن الأساس هيكون واضح.
