# أولًا: يعني إيه Load Balancer؟

## التعريف

الـ Load Balancer هو:

# وسيط بين المستخدم والسيرفرات

وظيفته:  
يوزع الـ requests على مجموعة Servers بدل ما Server واحد يشيل كل الحمل.

---

# المشكلة الأساسية

تخيل عندك:

```text
Users → Server
```

لو دخل:

- 10 مستخدمين → تمام
    
- 10,000 مستخدم → السيرفر يقع ❌
    

---

# الحل

نشغل أكتر من Server:

```text
Users
   ↓
Load Balancer
 ↓   ↓   ↓
S1  S2  S3
```

الـ Load Balancer يوزع الناس.

---

# فايدة Load Balancer

## 1. Scalability

يعني:  
تقدر تزود Servers بسهولة.

---

## 2. High Availability (HA)

حتى لو Server وقع…  
الباقي شغال.

ودي نقطة مهمة جدًا في الـ PDF.

---

# يعني إيه High Availability؟

يعني:  
السيستم يفضل شغال طول الوقت.

مثال:

- Facebook
    
- Netflix
    
- Amazon
    

مينفعش يقعوا.

---

# مثال عملي جدًا

بدل:

```text
1 Server
```

نعمل:

```text
3 Servers
```

لو واحد وقع:

```text
S1 ❌
S2 ✅
S3 ✅
```

الموقع يفضل شغال.

# الأول نفهم DNS

# يعني إيه DNS؟

DNS =

# Domain Name System

وده:

# مترجم الإنترنت

---

# لأن الكمبيوتر بيفهم IP

لكن البشر تحفظ:

```text
google.com
```

مش:

```text
142.250.190.14
```

---

# فالـ DNS بيحول:

```text
google.com
```

إلى:

```text
142.250.x.x
```

---

# DNS Resolution Flow

```text
Browser
   ↓
DNS Resolver
   ↓
DNS Server
   ↓
Get IP Address
   ↓
Connect to Server
```

---

# طيب DNS Load Balancing بيشتغل إزاي؟

بدل ما الـ DNS يرجع IP واحد…

يرجع أكتر من IP.

مثال:

```text
skillhub.com
   ↓
192.168.1.1
192.168.1.2
192.168.1.3
```

---

# الـ Client ياخد IP مختلف كل مرة

وده اسمه:

# Round Robin

---

# يعني إيه Round Robin؟

يوزع بالترتيب:

```text
Request 1 → S1
Request 2 → S2
Request 3 → S3
```

---

# Advantages of DNS Load Balancing

الـ PDF ذكر:

## 1. Simple

سهل جدًا.

## 2. Cheap

رخيص جدًا.

---

# Drawbacks

ودي مهمة جدًا للانترفيوهات.

---

# 1. مفيش Health Check

الـ DNS:  
مش بيعرف السيرفر وقع ولا لأ.

---

# مثال

```text
S1 ❌
S2 ✅
S3 ✅
```

الـ DNS ممكن يفضل يبعت ناس لـ S1.

---

# 2. Round Robin فقط

الـ balancing بدائي.

يعني:  
مش ذكي.

---

# المشكلة

لو:

```text
S1 قوي
S2 ضعيف
```

هيتعاملوا نفس المعاملة.

---

# 3. Less Secure

الـ client يشوف IPs الحقيقية للسيرفرات.

وده خطر أمني.

---

# 4. No Traffic Intelligence

مش بيشوف:

- CPU
    
- RAM
    
- latency
    
- health

## 1. DNS Load Balancing
Uses DNS to distribute requests.

### Disadvantages
- No health checks

Physical device.

- NGINX

### Advantages
- Flexible
- Cheap
- Smart algorithms

## Round Robin
Distributes requests equally.
