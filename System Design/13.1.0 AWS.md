أيوه بالظبط! AWS بيوفر ده بشكل كامل 👇

## الخدمات اللي بتحتاجها على AWS

**١. السيرفرات** → **EC2 Instances**

- بتعمل كام instance (سيرفر) عايزه

**٢. الـ Load Balancer** → **ALB (Application Load Balancer)**

- خدمة جاهزة من AWS بتوزع الـ requests على الـ EC2s

---

## الصورة الكاملة

```
Users
  ↓
ALB (Load Balancer)
  ↓          ↓          ↓
EC2-1      EC2-2      EC2-3
```

---

## وكمان AWS بيوفر

|الخدمة|الفايدة|
|---|---|
|**Auto Scaling**|لو الـ traffic زاد، يضيف سيرفرات أوتوماتيك|
|**Target Groups**|بتحدد فيها انهي سيرفرات اللي الـ LB يوزع عليهم|
|**Health Checks**|لو سيرفر وقع، الـ LB بيبطل يبعتله requests|
